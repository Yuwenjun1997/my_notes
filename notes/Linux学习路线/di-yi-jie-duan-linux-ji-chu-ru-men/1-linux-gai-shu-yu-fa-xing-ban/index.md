# Linux 概述与发行版

## 一、Linux 是什么

### 1.1 Linux 内核与 GNU 项目

Linux 严格来说只是**内核（Kernel）**，负责管理硬件资源（CPU、内存、磁盘、网络）。我们日常使用的"Linux 系统"实际上是 **GNU/Linux**——Linux 内核 + GNU 工具链（shell、编译器、核心工具等）。

```text
┌──────────────────────────────────────┐
│          用户应用程序                  │
├──────────────────────────────────────┤
│      Shell (bash/zsh) / GUI          │  ← 用户接口
├──────────────────────────────────────┤
│      GNU 核心工具 (coreutils)         │  ← ls, cp, cat, grep...
├──────────────────────────────────────┤
│      Linux 内核 (Kernel)              │  ← 硬件抽象、进程调度、内存管理
├──────────────────────────────────────┤
│      硬件 (CPU / 内存 / 磁盘 / 网络)    │
└──────────────────────────────────────┘
```

### 1.2 Linux 的优势

| 特性 | 说明 |
|:-----|:-----|
| **开源免费** | GPL 许可证，源码开放，无授权费用 |
| **稳定性** | 服务器可运行数年不重启 |
| **安全性** | 权限模型严格，病毒/恶意软件少 |
| **灵活性** | 高度可定制，从嵌入式到超算均可运行 |
| **生态丰富** | 几乎所有服务器软件优先支持 Linux |
| **社区强大** | 遇到问题有大量文档和社区支持 |

## 二、主流发行版对比

Linux 发行版（Distribution）= Linux 内核 + 包管理器 + 桌面环境 + 预装软件的组合。

### 2.1 发行版家族关系

```text
                    Debian                    Red Hat             独立
                      │                         │                  │
              ┌───────┼───────┐          ┌──────┼──────┐       Arch Linux
              ▼               ▼          ▼             ▼           │
           Ubuntu          Raspbian   RHEL          Fedora     Manjaro
              │                     (商业版)       (社区版)
      ┌───────┼───────┐
      ▼       ▼       ▼
   Kubuntu  Xubuntu  Linux Mint
```

### 2.2 主流发行版对比

| 发行版 | 包管理器 | 特点 | 适用场景 |
|:-------|:---------|:-----|:---------|
| **Ubuntu** | apt (deb) | 用户友好、文档丰富、社区活跃、LTS 长期支持 | **首选**：开发、服务器、桌面 |
| **Debian** | apt (deb) | 极其稳定、保守的软件版本 | 生产服务器 |
| **CentOS Stream** | dnf (rpm) | RHEL 的上游滚动版 | 企业级服务器（替代旧 CentOS） |
| **Rocky Linux** | dnf (rpm) | RHEL 兼容的社区版 | CentOS 迁移首选 |
| **Fedora** | dnf (rpm) | 新技术试验场，更新快 | 桌面开发 |
| **Arch Linux** | pacman | 滚动更新，高度定制 | Linux 进阶玩家 |
| **Alpine** | apk | 极致轻量（~5MB） | Docker 容器镜像 |

### 2.3 为什么选 Ubuntu？

对 Java 后端开发者而言，Ubuntu 是最佳选择：

* **LTS 版本**：每两年发布一次长期支持版（如 22.04、24.04），提供 5 年安全更新
* **软件丰富**：apt 仓库软件数量最大，PPA 扩展生态完善
* **文档最多**：遇到问题搜索 "ubuntu + 关键词" 几乎总能找到解决方案
* **云原生标准**：AWS/Azure/GCP 默认推荐 Ubuntu 镜像
* **桌面体验好**：GNOME 桌面 + Ubuntu 定制，对 Windows 迁移用户友好

## 三、Ubuntu 版本管理

### 3.1 版本号规则

Ubuntu 版本号格式：`YY.MM`（发布年份.月份）

```text
Ubuntu 20.04 LTS  →  2020年4月发布，长期支持
Ubuntu 22.04 LTS  →  2022年4月发布，长期支持
Ubuntu 24.04 LTS  →  2024年4月发布，长期支持
Ubuntu 23.10      →  2023年10月发布，非LTS（9个月支持）
```

### 3.2 LTS vs 非 LTS

| 对比维度 | LTS（长期支持版） | 非 LTS |
|:---------|:-----------------|:-------|
| 发布周期 | 每 2 年 | 每 6 个月 |
| 支持期限 | 5 年（Ubuntu Pro 可到 10 年） | 9 个月 |
| 软件版本 | 较稳定（偏旧） | 较新 |
| 服务器推荐 | ✅ 强烈推荐 | ❌ 不推荐 |
| 桌面推荐 | ✅ 推荐 | 尝鲜用户 |

> ⚠️ **注意事项**：生产环境务必使用 LTS 版本，非 LTS 仅适合体验新特性。

### 3.3 当前推荐版本

* **服务器**：Ubuntu 24.04 LTS 或 Ubuntu 22.04 LTS
* **桌面开发**：Ubuntu 24.04 LTS
* **WSL2 学习**：Ubuntu 24.04 LTS

## 四、常用 Linux 术语速查

| 术语 | 说明 |
|:-----|:-----|
| **内核（Kernel）** | 操作系统的核心，管理硬件与进程 |
| **发行版（Distribution）** | 内核 + 软件包集合 + 包管理器的组合 |
| **Shell** | 命令行解释器，用户与内核交互的桥梁 |
| **终端（Terminal）** | 运行 Shell 的窗口程序 |
| **包管理器** | 安装/更新/卸载软件的工具（如 apt） |
| **仓库（Repository）** | 软件包的远程存储服务器 |
| **Root** | 超级用户，拥有系统最高权限 |
| **守护进程（Daemon）** | 后台运行的服务进程 |

## 📝 实践项目

### 目标

了解 Ubuntu 版本信息，熟悉发行版相关操作。

### 步骤

1. **查看当前系统信息**
   ```bash
   uname -a
   lsb_release -a
   cat /etc/os-release
   ```

2. **查看内核版本**
   ```bash
   cat /proc/version
   hostnamectl
   ```

3. **了解系统架构**
   ```bash
   arch          # 查看 CPU 架构（x86_64 / aarch64）
   dpkg --print-architecture   # 查看包架构
   ```

4. **浏览 Ubuntu 官网**
   访问 https://ubuntu.com/download 了解最新 LTS 版本
