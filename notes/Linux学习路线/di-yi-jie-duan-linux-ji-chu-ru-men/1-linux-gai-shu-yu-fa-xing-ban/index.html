1-Linux概述与发行版

一、Linux 是什么

1.1 Linux 内核与 GNU 项目

Linux 严格来说只是内核（Kernel），负责管理硬件资源（CPU、内存、磁盘、网络）。我们日常使用的"Linux 系统"实际上是 GNU/Linux——Linux 内核 + GNU 工具链（shell、编译器、核心工具等）。

┌──────────────────────────────────────┐
│          用户应用程序                  │
├──────────────────────────────────────┤
│      Shell (bash/zsh) / GUI          │  ← 用户接口
├──────────────────────────────────────┤
│      GNU 核心工具 (coreutils)         │  ← ls, cp, cat, grep...
├──────────────────────────────────────┤
│      Linux 内核 (Kernel)              │  ← 硬件抽象、进程调度、内存管理
├──────────────────────────────────────┤
│      硬件 (CPU / 内存 / 磁盘 / 网络)    │
└──────────────────────────────────────┘

1.2 Linux 的优势

特性说明
开源免费GPL 许可证，源码开放，无授权费用
稳定性服务器可运行数年不重启
安全性权限模型严格，病毒/恶意软件少
灵活性高度可定制，从嵌入式到超算均可运行
生态丰富几乎所有服务器软件优先支持 Linux
社区强大遇到问题有大量文档和社区支持

2.3 为什么选 Ubuntu？

对 Java 后端开发者而言，Ubuntu 是最佳选择：

  • LTS 版本：每两年发布一次长期支持版（如 22.04、24.04），提供 5 年安全更新
  • 软件丰富：apt 仓库软件数量最大，PPA 扩展生态完善
  • 文档最多：遇到问题搜索 "ubuntu + 关键词" 几乎总能找到解决方案
  • 云原生标准：AWS/Azure/GCP 默认推荐 Ubuntu 镜像
  • 桌面体验好：GNOME 桌面 + Ubuntu 定制，对 Windows 迁移用户友好

三、Ubuntu 版本管理

3.1 版本号规则

Ubuntu 版本号格式：YY.MM（发布年份.月份）

Ubuntu 20.04 LTS  →  2020年4月发布，长期支持
Ubuntu 22.04 LTS  →  2022年4月发布，长期支持
Ubuntu 24.04 LTS  →  2024年4月发布，长期支持
Ubuntu 23.10      →  2023年10月发布，非LTS（9个月支持）

3.2 LTS vs 非 LTS

对比维度LTS（长期支持版）非 LTS
发布周期每 2 年每 6 个月
支持期限5 年（Ubuntu Pro 可到 10 年）9 个月
软件版本较稳定（偏旧）较新
服务器推荐✅ 强烈推荐❌ 不推荐
桌面推荐✅ 推荐尝鲜用户

⚠️ 注意事项：生产环境务必使用 LTS 版本，非 LTS 仅适合体验新特性。

3.3 当前推荐版本

  • 服务器：Ubuntu 24.04 LTS 或 Ubuntu 22.04 LTS
  • 桌面开发：Ubuntu 24.04 LTS
  • WSL2 学习：Ubuntu 24.04 LTS

五、进阶：版本识别、内核解读与心智模型

5.1 /etc/os-release：脚本里判断发行版的标准姿势

cat /etc/os-release
# NAME="Ubuntu"
# VERSION="24.04.1 LTS (Noble Numbat)"
# ID=ubuntu
# VERSION_ID="24.04"
# VERSION_CODENAME=noble
# ID_LIKE=debian
# PRETTY_NAME="Ubuntu 24.04.1 LTS"

# 脚本里取关键字段（比解析 lsb_release 更通用）⭐
. /etc/os-release && echo "发行版: $ID $VERSION_ID, 代号: $VERSION_CODENAME"

# 判断发行版系，决定用 apt 还是 dnf/yum
. /etc/os-release
case "$ID_LIKE" in
  debian) echo "用 apt" ;;
  rhel)   echo "用 dnf/yum" ;;
esac

💡 /etc/os-release 被几乎所有主流发行版支持，是纯文本键值对，脚本里 source 它即可拿到稳定的 ID/版本号——运维脚本判断环境的通用做法。

5.2 内核版本号逐段解读

uname -a
# Linux hostname 6.8.0-31-generic #31-Ubuntu SMP PREEMPT_DYNAMIC x86_64 GNU/Linux
#       ①主机名   ②内核版本          ③构建信息             ④架构
段含义
6主版本号（大版本演进）
8次版本号（功能新增；奇数=开发版，偶数=稳定版）
0修订号（补丁/修复）
31Ubuntu 自有的补丁号
generic内核风味：generic（通用）、lowlatency（低延迟）、server
x86_64CPU 架构
uname -r      # 只显示内核版本
uname -m      # 只显示架构
uname -s      # 内核名（Linux）

5.3 Ubuntu 版本代号规律

lsb_release -a        # 发行版全信息
lsb_release -c        # 只看代号
lsb_release -r        # 只看版本号

💡 Ubuntu 代号规律：形容词 + 动物名，按字母序递增：20.04 focal → 22.04 jammy → 24.04 noble。换 apt 源时"代号"必须和系统匹配（1.2 §3 的坑）——用 lsb_release -c 或 /etc/os-release 的 VERSION_CODENAME 确认，别照抄网上的旧代号。

5.4 Linux vs Windows 心智模型对比

维度WindowsLinux迁移要点
盘符C: D:一个根 /，设备挂到目录下（/home、/data）没有盘符概念，看 /
路径分隔\/大小写敏感：File.txt ≠ file.txt
软件安装双击 .exe包管理器 apt install装软件先 apt update
权限管理员/UAC每个文件有 owner/group/others + rwxsudo 临时提权
换行符\r\n (CRLF)\n (LF)文件传 Windows 后可能出现 ^M（2.7 cat -A）
服务服务管理器systemd + systemctl开机自启用 systemctl enable

📝 实践项目

目标

了解 Ubuntu 版本信息，熟悉发行版相关操作。

步骤

  1. 查看当前系统信息

    uname -a
lsb_release -a
cat /etc/os-release

  2. 查看内核版本

    cat /proc/version
hostnamectl

  3. 了解系统架构

    arch          # 查看 CPU 架构（x86_64 / aarch64）
dpkg --print-architecture   # 查看包架构

  4. 浏览 Ubuntu 官网 访问 https://ubuntu.com/download 了解最新 LTS 版本
