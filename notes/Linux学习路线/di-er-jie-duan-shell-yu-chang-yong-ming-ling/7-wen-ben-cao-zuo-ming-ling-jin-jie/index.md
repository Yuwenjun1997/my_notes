# 文本操作命令进阶

**2.6 文本查看与编辑** 讲了 less/vim/nano 的完整键位；本篇是它的"进阶武器"篇——**不再重复快捷键表**，而是聚焦三件事：把 `cat` 从"查看"升级为"构建文件"、一张速查卡收齐所有查看命令、把 vim 的快捷键用成可复用的**工作流**（宏、可视块、寄存器、批量替换）。

## 一、cat 高阶用法：从"查看"到"构建文件"

`cat` 的基础用法（`cat` / `cat -n` / `tac`）已在 **2.2 §1.4 查看文件内容** 讲过。这一节只讲 2.2 没有的**选项与文件构建能力**——记住：`cat` 的核心是**把文件当作字节流**，既能读出来，也能拼起来、写进去。

### 1.1 显示不可见字符

```bash
cat -A config.txt          # ⭐ 显示所有不可见字符（最常用）
cat -E config.txt          # 只显示行尾（每行末尾加 $）
cat -T config.txt          # 只显示制表符（Tab 显示为 ^I）
cat -s config.txt          # 压缩连续空行为一个空行
cat -b config.txt          # 给非空行编号（空行不编号）

# 实战：检测 Windows 换行符（DOS 回车显示为 ^M）
cat -A app.log | head      # 看到行尾有 ^M 说明是 DOS 格式（\r\n）
# 实战：检查配置文件是否有多余空格/制表符
cat -A /etc/nginx/nginx.conf | grep '\$$'   # 找出行尾有多余空格的行
```

| 选项 | 作用 | 典型场景 |
|:-----|:-----|:---------|
| `-n` | 给所有行编号（含空行） | 2.2 已讲，展示代码/日志行号 |
| `-b` | 只给非空行编号 | 编号时跳过空行 |
| `-A` | 显示所有不可见字符（= `-vET`） | ⭐ 诊断换行符、多余空格、Tab |
| `-E` | 行尾显示 `$` | 单独检查行尾空白 |
| `-T` | Tab 显示为 `^I` | 检查缩进是空格还是 Tab |
| `-s` | 压缩连续空行 | 清理脚本输出、压缩日志空行 |

### 1.2 多文件拼接与追加

```bash
cat a.txt b.txt > c.txt            # ⭐ 合并多个文件到 c.txt
cat a.txt >> b.txt                 # 把 a 追加到 b 末尾
cat file1.txt file2.txt file3.txt  # 依次输出三个文件
cat *.md > 全部.md                  # 通配符拼接目录下所有 md
cat part1 part2 > 完整文件          # 还原被 split 分卷的文件（split -b 见 3.1）

# 用 cat 临时合并后交给其他命令
cat a.log b.log | grep ERROR       # 合并两个日志再搜索
```

> 💡 **拼接 vs 复制**：`cat a b > c` 是**内容流**操作，把 a、b 的内容依次写入 c；`cp`/`mv` 是**文件级**操作（保留权限、复制整个 inode）。要给文件加"头"或合并多个配置片段，用 `cat` 最顺手。

### 1.3 heredoc：一次性写文件

heredoc 的概念已在 **2.1 §5.3 输入输出重定向与管道** 讲过，这里深化两个容易踩的细节：**引号与缩进**。

```bash
# 写法一：EOF 加单引号 → 内容原样写入，变量不展开
cat > /tmp/config.conf << 'EOF'
server {
    port = ${APP_PORT}     # 原样保留 ${APP_PORT}，不替换
    host = "10.0.0.1"
}
EOF

# 写法二：EOF 不带引号 → 变量会展开 ⭐
PORT=8080
cat > /tmp/app.env << EOF
APP_PORT=$PORT             # 被替换为 APP_PORT=8080
APP_HOME=/opt/app
EOF

# 写法三：<<- 忽略行首 Tab（适合在缩进的脚本里写配置）
cat > /tmp/conf.ini <<- 'EOF'
	[key]                   # 行首的 Tab 会被去掉
	value = 1
	EOF

# 追加而不是覆盖：<< 配合 >> 即可
cat >> /tmp/app.env << 'EOF'
APP_LOG=info
EOF
```

> ⚠️ **坑**：
>
> * `EOF` 结束标记必须**顶格写**（行首不能有空格），除非用 `<<-`。
> * 不加引号的 `EOF` 会做变量/命令展开，如果内容里有 `$`（如正则、配置文件里的 `$` 变量），务必加引号 `'EOF'`。
> * heredoc 不只是 `cat` 的专利，`tee` 也能用：`tee config.txt << 'EOF' ... EOF`，区别是 tee 会同时输出到屏幕（还能追加 `-a`）。

**四选一：往文件写内容用哪个？**

| 工具 | 特点 | 适用场景 |
|:-----|:-----|:---------|
| `cat > file` | 逐行输入直到 Ctrl+D，或配合 heredoc | ⭐ 多行内容、生成配置文件 |
| `echo "..." > file` | 简单一行文本 | 写单行、写变量值 |
| `printf "..." > file` | 支持格式串 `%s`/`%d`/`\n` | 需要格式化输出时 |
| `tee file` | 一边写文件一边显示在终端，支持 `-a` 追加 | 需要"所见即所得"的确认 |

### 1.4 cat 常见坑

> ⚠️ **大文件别用 cat 看**：`cat 大文件 | head` 会先把整份文件读进管道，触发 SIGPIPE 报 `Broken pipe`。直接 `head 大文件`、`less 大文件` 更高效（**2.6 §二**）。
> ⚠️ **cat 二进制会乱码**：`cat binary.img` 会往终端喷乱码。要看二进制用 `od -c` / `xxd`（见 **2.3 特殊查看技巧**）。
> 💡 想实时看文件尾部变化，用 `tail -f` 而不是 `cat`（**2.2 §1.4**）。

## 二、查看命令全家桶速查卡

**2.6 §一** 的对比表覆盖了 cat/head/tail/more/less/vim/nano。这里补上没进那张表的 `tac`/`nl`/`rev`/`od`，构成一张完整的"查看命令全家桶"。

### 2.1 全景速查卡

| 命令 | 方向 | 翻页 | 搜索 | 行号 | 实时跟踪 | 编辑 | 典型场景 |
|:-----|:-----|:----:|:----:|:----:|:--------:|:----:|:---------|
| `cat` | 从头到尾 | ❌ | ❌ | `-n` | ❌ | ❌ | 小文件、拼接 |
| `tac` | 从尾到头 | ❌ | ❌ | ❌ | ❌ | ❌ | 逆序输出（倒看日志） |
| `nl` | 从头到尾 | ❌ | ❌ | ✅ | ❌ | ❌ | 编号输出（比 cat -n 灵活） |
| `rev` | 每行反转 | ❌ | ❌ | ❌ | ❌ | ❌ | 逐行字符反转 |
| `head` | 开头 N 行 | ❌ | ❌ | ❌ | ❌ | ❌ | 看文件头 |
| `tail` | 末尾 N 行 | ❌ | ❌ | ❌ | `-f/-F` | ❌ | 看日志最新、实时跟踪 |
| `less` | 自由 | ✅ | ✅ | `-N` | `F` | ❌ | ⭐ 大文件、长输出分页 |
| `more` | 仅向下 | 部分 | 有限 | ❌ | ❌ | ❌ | 老习惯（已被 less 取代） |
| `od` | 从头到尾 | ❌ | ❌ | ❌ | ❌ | ❌ | 八进制/十六进制看二进制 |

> 💡 记忆口诀：**看方向找 tac/rev，看开头 head、看结尾 tail，分页搜索全用 less，乱码诊断找 od**。

### 2.2 nl 与 cat -n 的区别

`cat -n` 只能简单编号，`nl` 可控制**编号格式、宽度、是否包含空行**：

```bash
nl file.txt                    # 默认：非空行编号，空行不编号
nl -ba file.txt                # ⭐ 所有行编号（含空行）= cat -n
nl -w 3 file.txt               # 编号宽度占 3 位（右对齐补空格）
nl -s '. ' file.txt            # 编号和正文之间用 ". " 分隔
nl -n ln file.txt              # 编号左对齐（ln）/右对齐(rn)/补零(z1)
nl -v 100 file.txt             # 起始编号从 100 开始
```

### 2.3 特殊查看技巧

```bash
tail -n +10 file.txt           # ⭐ 从第 10 行开始显示（跳过前 9 行）
head -n -3 file.txt            # 显示除最后 3 行外的所有行（负数 = 去掉末尾 N 行）
sed -n '10,20p' file.txt       # 只取第 10-20 行（中段，sed 详见 2.3 §三）
sed -n '10p' file.txt          # 只取第 10 行

rev file.txt                   # 每行字符左右反转（如 1234 → 4321）
rev file.txt | sort | rev      # 按"行尾内容"排序的取巧技巧

od -c file.bin | head          # 按字符查看二进制（乱码诊断）⭐
od -An -tx1 file.bin           # 纯十六进制字节
xxd file.bin                   # 十六进制 + 左侧 ASCII 对照（更直观）
xxd file.bin | head            # 查看文件头几个字节（校验魔数，如 PNG 的 89 50 4E 47）
```

> 💡 `tail -n +N` 常用于"跳过表头取数据"：`tail -n +2 data.csv` 取掉 CSV 首行表头。

## 三、vim 进阶技巧：把快捷键用成工作流

前提：已掌握 **2.3 §六 vim 基础操作** 和 **2.6 §四 vim 完整快捷键**。本节**不再罗列键位表**，只讲把键位组合成可复用工作流的四类技巧。

### 3.1 宏录制（q）—— 把重复操作录成"一键"

宏是 vim 里最划算的进阶技能：录一遍，回放 N 遍。

```text
操作流程：
q a          开始录制到寄存器 a
   ...执行要重复的操作（插入、删除、替换、移动...）
q            结束录制
@a           回放一次
5@a          回放 5 次
@@           重复上一次回放
```

```text
实战：给 20 行数据每行加 "name:" 前缀
1. gg 到第一行 → q a → I  → 输入 name: → Esc → j（下一行）→ q
2. 20@a  批量执行 20 次（每次回到行首、加前缀、跳到下一行）
```

```text
实战：把日志行转成 CSV（把空格分隔替换为逗号）
1. 光标在第一行 → q b → :s/ \+/,/g → 回车 → j → q
2. 99@b  把前 100 行全部转成 CSV
```

> 💡 宏配对的黄金套路：**让宏以"回到起始位置 + 移动到下一行"收尾**（如 `I...Esc j`），这样重复执行时才会逐行推进，不会卡在同一行。

### 3.2 可视块编辑（Ctrl+v）—— 多列同时改

```text
Ctrl+v       进入可视块模式（选中矩形区域）
  移动 j/k/l/h  框住要操作的列
I 内容 Esc   批量插入（每行选中的列前都插入）⭐
d / x        批量删除选中的列
~            批量切换大小写
> / <        批量缩进 / 反缩进
```

```text
实战：给 50 行配置批量加注释（# 加到行首）
1. Ctrl+v → 框选 1-50 行的第一列 → I → 输入 # → Esc
   所有选中行行首同时出现 #  ⭐
实战：删除每行开头的 4 个空格缩进
1. Ctrl+v → 框选前 4 列 → d
```

> ⚠️ 批量插入 `I` 后必须按 `Esc` 才会真正应用到所有选中行，而且插入的内容会保留，注意先看状态栏确认仍在可视块模式。

### 3.3 寄存器应用 —— vim 的多块剪贴板

**2.6 §4.2** 列过寄存器基础键位，这里讲**应用场景**：vim 有多个独立的"剪贴板"，互不覆盖。

| 寄存器 | 名称 | 内容 | 适用场景 |
|:-------|:-----|:-----|:---------|
| 无名寄存器 | `""` | 最近一次删除/复制 | 日常 `dd`/`yy`/`p` |
| 编号寄存器 | `"0`-`"9` | 最近 10 次操作历史 | `"0p` 找回刚才误删的内容 |
| 命名寄存器 | `"a`-`"z` | 用户指定 | ⭐ 临时保存多段内容 |
| 黑洞寄存器 | `"_` | 丢弃 | 删除但不想污染剪贴板 |
| 系统剪贴板 | `"+` | 与系统剪贴板互通 | 复制到系统粘贴到别处 |

```text
实用场景：
"ayy    复制当前行到寄存器 a
"ap     粘贴寄存器 a 的内容
"+yy    复制到系统剪贴板（可在浏览器/IDE 里 Ctrl+V）⭐
"+p     粘贴系统剪贴板内容
dd      删错了 → "0p  把刚才删的那一行找回来 ⭐
"_dd    删除但不覆盖剪贴板（黑洞）
:reg    查看所有寄存器的内容
```

### 3.4 多文件批量操作 —— diff、bufdo、vimgrep

**2.6 §4.2** 已讲多文件/分屏/标签的键位，这里补充**以"批量"为目的**的用法：

```bash
vim -d a.conf b.conf        # ⭐ diff 模式打开两个文件对比
```

| 按键/命令 | 作用 |
|:----------|:-----|
| `]c` / `[c` | 跳到下一处 / 上一处差异 |
| `do` | 把对方文件的差异"取过来"（diff obtain） |
| `dp` | 把当前差异"推过去"（diff put） |
| `:diffupdate` | 手动重新计算差异 |
| `:diffthis` | 在普通分屏中开启 diff |

```bash
# 批量替换所有打开文件（缓冲）中的内容：bufdo = 对每个缓冲执行
:bufdo %s/8080/9090/g | update    # ⭐ 每个文件替换后自动保存

# 多文件搜索（vimgrep，结果可用 :copen 查看）
:vimgrep /ERROR/ src/**/*.java    # 在 src 下所有 java 文件搜 ERROR
:copen                            # 打开结果列表，回车跳转
:cnext / :cprev                   # 下一个 / 上一个匹配
```

> 💡 运维场景：改了端口要同步到多个配置，`vim a.conf b.conf c.conf` 打开后 `:bufdo %s/8080/9090/g | update` 一键搞定，再 `:qall` 退出。

### 3.5 查找替换进阶 —— 从"替换"到"删除/范围/正则"

**2.3 §6.2** 讲了 `:%s/old/new/g`。这里补充更强大的变体：

```text
删除匹配行 / 保留匹配行
:g/pattern/d         删除所有匹配 pattern 的行 ⭐
:g!/pattern/d        删除所有"不匹配"的行（只保留匹配行）
:v/pattern/d         同 :g! 的简写

范围替换
:1,10s/old/new/g     只替换第 1-10 行
:.,$s/old/new/g      从当前行到文件末尾
:/start/,/end/s/old/new/g   在两个标记之间的范围替换

正则进阶（配合 2.3 §2.2 的正则基础）
:%s/\v(\w+)@\w+\.com/@example.com/g    \v = very magic 模式，\1 = 第一组捕获
:%s/\v(^\s*)(#.*)?/\1#\2/              给非注释行批量加注释（保留原缩进）
```

```text
表达式替换（:s 的结果里用 \= 调用 vim 表达式）—— 在普通替换里做"计算"
:%s/^/\=printf('%-3d ', line('.'))/    每行行首插入行号（2.3 实践项目出现过）
:%s/\v(\d+)/\=submatch(1)*2/g          把所有数字翻倍
```

## 四、nano 进阶配置 —— 轻量也顺手

**2.6 §五** 讲了 nano 的基础键位和适用场景。这里补配置与多缓冲，让它日常改配置更顺手。

### 4.1 .nanorc 配置文件

nano 的用户配置在 `~/.nanorc`（全局在 `/etc/nanorc`），保存后立即生效：

```text
# ~/.nanorc 示例
set linenumbers        # 显示行号 ⭐
set tabsize 4          # Tab 宽度 4
set autoindent         # 自动缩进
set nowrap             # 长行不自动换行
set mouse              # 支持鼠标点击定位

# 启用常见语法高亮（Debian/Ubuntu 自带语法定义）
include /usr/share/nano/*.nanorc
```

### 4.2 多缓冲与正则替换

nano 的编辑能力弱于 vim，但几个进阶键能显著提速：

| 按键 | 作用 |
|:-----|:-----|
| `M-,` / `M-.` | 切换到上一个 / 下一个缓冲（打开多个文件时） |
| `M-<` / `M->` | 跳到文件开头 / 末尾 |
| `M-R` | 正则表达式替换 ⭐（如 `M-R` 后 `^ *` 可去行首空格） |
| `M-U` / `M-E` | 撤销 / 重做 |
| `M-\\` | 补全单词 |

> 💡 没有宏、没有可视块、没有 `:g`，nano 的批量能力确实弱（**2.6 §5.3** 已说明取舍）。超过"改几行配置"的重活，回 vim 用第三章的宏/可视块/批量替换。

## 📝 实践项目

### 目标

用高级文本技巧完成一次"文件处理流水线"：从诊断、生成、拼接到批量编辑。

### 步骤

1. **诊断换行符并修复**

   ```bash
   printf 'a\r\nb\r\nc\n' > dos.txt
   cat -A dos.txt        # 看到 ^M 说明是 DOS 换行
   sed -i 's/\r$//' dos.txt    # 去掉行尾 ^M（sed 详见 2.3 §三）
   cat -A dos.txt        # 确认 ^M 消失
   ```

2. **heredoc 生成配置 + cat 拼接**

   ```bash
   cat > app.env << 'EOF'
   PORT=8080
   LOG=info
   EOF
   cat header.txt app.env footer.txt > 完整配置.conf   # 三段拼接
   cat -n 完整配置.conf
   ```

3. **查看命令全家桶练习**

   ```bash
   seq 1 100 > nums.txt
   nl -ba nums.txt | tail -5        # 编号 + 只看末尾 5 行
   tail -n +95 nums.txt             # 跳过前 94 行
   rev <(echo "hello")              # 输出 olleh（进程替换见 2.1）
   xxd nums.txt | head              # 用十六进制看文件头
   ```

4. **vim 宏批量加序号前缀**

   ```text
   打开 20 行数据 → gg → q a → I → 输入 "1. " → Esc → j → q
   改数字后（2. 3. ...）用可视块批量递增：Ctrl+v 框住行首数字 → 然后 20@a 前先手动改一列
   简化练习：只加统一前缀 "item-" → q a → I item- → Esc → j → q → 19@a
   ```

5. **可视块批量注释 / 反注释**

   ```text
   vim 一个 30 行的 shell 脚本 → Ctrl+v 框住前 1 列 → I → 输入 # → Esc
   全部加注释；再次框选 → d 全部取消注释
   ```

6. **:bufdo 批量替换端口**

   ```bash
   mkdir -p ~/txt-practice && cd ~/txt-practice
   echo 'port=8080' > a.conf && echo 'port=8080' > b.conf
   vim a.conf b.conf        # 打开后：
   #   :bufdo %s/8080/9090/g | update   两个文件都替换并保存
   #   :qall                             全部退出
   ```

### 进阶挑战

* 用宏把一段 `access.log`（空格分隔）转成 CSV，再统计转换后的行数。
* 用 `vimdiff`（`vim -d a.conf b.conf`）对比并同步两个配置文件的差异。
* 写一份自己的 `~/.nanorc`（含 `set linenumbers` + 语法高亮），并验证改配置时行号生效。
* 用 `od -An -tx1` 查看任意文件的**魔数**（前 8 字节），验证它是不是正确的文件类型。
