🎨 第一阶段：网页基础

学习周期：1-2 周 | 每日建议：2-3 小时 目标：掌握 HTML 结构、表单与 CSS 盒模型/布局/响应式，能写出语义化、可适配的静态页面。

💡 学习建议

  1. 动手优先：每个知识点都要在浏览器里实际写一遍，只看文档是记不住的。用 CodePen 或本地 Vite 项目练手。
  2. 善用 DevTools：按 F12 打开开发者工具，Elements 改样式、Console 跑 JS、Network 看请求、Sources 断点调试。
  3. 以 MDN 为第一参考：遇到 API 用法先查 MDN Web Docs（MDN 也比多数中文博客准确）。
  4. 每章留小练习：学完一个模块，给自己出一个小题目（如写一个轮播、一个卡片列表），检验是否真的会了。
  5. 建立自己的代码库：把常用工具函数、样式片段（见 1.6、4.2）沉淀成自己的片段库，日后事半功倍。
