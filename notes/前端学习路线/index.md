## 📐 学习路线总览

```
第一阶段：网页基础（1-2周）
    │  HTML → HTML表单 → CSS盒模型 → flex/grid布局 → 响应式动画 → 常用样式
    ▼
第二阶段：JavaScript 核心（3-4周）
    │  语言基础 → 函数与闭包 → 原型与this → 异步与事件循环 → ES6+ → DOM → 数组
    ▼
第三阶段：TypeScript（2-3周）
    │  编译 → 类型基础 → 枚举 → 接口 → 类 → 泛型 → 函数 → 类与接口
    ▼
第四阶段：工程化与实战（3-4周）
    │  Vite构建工具 → 工具函数 → 上传图片 → 二维码 → 上拉加载 → 可折叠列表 → Excel解析
    ▼
第五阶段：可视化编辑器与低代码技术（4-6周）
    低代码架构 → dnd-kit拖拽 → Schema渲染 → Formily表单引擎
    → 页面编辑器架构 → 编辑器实战 → TipTap富文本 → React Flow流程图
    → 组件生态与案例 → 预览发布与沙箱
```

### 💡 学习建议

1. **动手优先**：每个知识点都要在浏览器里实际写一遍，只看文档是记不住的。用 CodePen 或本地 Vite 项目练手。
2. **善用 DevTools**：按 `F12` 打开开发者工具，Elements 改样式、Console 跑 JS、Network 看请求、Sources 断点调试。
3. **以 MDN 为第一参考**：遇到 API 用法先查 [MDN Web Docs](https://developer.mozilla.org/)（MDN 也比多数中文博客准确）。
4. **每章留小练习**：学完一个模块，给自己出一个小题目（如写一个轮播、一个卡片列表），检验是否真的会了。
5. **建立自己的代码库**：把常用工具函数、样式片段（见 1.6、4.2）沉淀成自己的片段库，日后事半功倍。
