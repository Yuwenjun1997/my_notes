HTML表单

约 821 字大约 3 分钟

2026-08-17

表单用于收集用户输入并提交给后端，是网页与用户交互的核心手段。

form 元素

<form action="/api/login" method="POST">
  <!-- 表单控件 -->
</form>
  • action：提交到的服务器地址。
  • method：GET（参数在 URL 中）或 POST（参数在请求体里）。
  • 表单按钮点击后会执行浏览器内置的提交逻辑；也可以拦截后用 FormData 异步提交（见实战篇的图片上传）。

input 类型

input 通过 type 属性决定形态：

type说明
text单行文本（默认）
password密码框，内容打点显示
radio单选项，同一组用相同 name
checkbox多选框
file文件选择
number数字输入，带上下箭头
date / time日期/时间选择
range滑块
hidden隐藏字段，随表单提交但不显示
search / email / url带语义的文本输入，移动端会调起对应键盘
<input type="text" name="username" placeholder="请输入用户名" required />
<input type="password" name="password" minlength="6" />
<input type="radio" name="gender" value="male" /> 男
<input type="radio" name="gender" value="female" /> 女
<input type="checkbox" name="hobby" value="coding" /> 编程
<input type="file" name="avatar" accept="image/*" />

常用属性

属性作用
name提交时的字段名，必填，否则字段不会被提交
value默认值；checkbox/radio 提交的是 value
placeholder占位提示文本（不随表单提交）
required必填校验
readonly只读，仍随表单提交
disabled禁用，不随表单提交
maxlength / min / max长度/数值范围限制

select 与 textarea

<select name="city">
  <option value="beijing">北京</option>
  <option value="shanghai" selected>上海</option>
</select>

<textarea name="intro" rows="4" cols="30">默认内容</textarea>

select 的 selected 指定默认选项；textarea 的内容写在标签中间，而非 value 属性。

label 关联

label 将说明文字与控件绑定：点击文字即可聚焦/选中控件，也方便屏幕阅读器。

<label for="email">邮箱</label>
<input id="email" type="email" name="email" />

<!-- 写法二：把控件包在 label 里，无需 id/for -->
<label>手机号 <input type="tel" name="phone" /></label>

分组：fieldset 与 legend

<fieldset>
  <legend>联系方式</legend>
  <label>邮箱 <input type="email" name="email" /></label>
  <label>电话 <input type="tel" name="phone" /></label>
</fieldset>

原生表单校验

浏览器内置校验规则，无需额外 JS：

  • required：不能为空。
  • type="email" 等：格式校验。
  • pattern="\d{11}"：正则校验。
  • min / max / minlength / maxlength：数值/长度范围。

提交时若校验失败，浏览器会阻止提交并提示。用 JS 可监听 invalid 事件自定义提示文案，或用 form.checkValidity() 主动触发校验。

完整示例：登录表单

<form action="/api/login" method="POST" novalidate>
  <fieldset>
    <legend>登录</legend>
    <label>用户名 <input type="text" name="username" required autofocus /></label>
    <label>密码 <input type="password" name="password" required minlength="6" /></label>
  </fieldset>
  <button type="submit">登录</button>
</form>
  • novalidate：临时关闭原生校验，便于先用 JS 校验。
  • <button type="submit"> 触发提交；type="button" 的按钮不提交。

提交方式小结

  1. 原生提交：点击 submit，浏览器按 action/method 跳转或刷新页面。
  2. 异步提交（常用）：e.preventDefault() 拦截默认行为，用 new FormData(form) 或手动取值，配合 fetch/ajax 无刷新提交（可参考第四阶段「图片上传」相关笔记）。
