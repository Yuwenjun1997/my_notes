CSS基础与盒模型

约 819 字大约 3 分钟

2026-08-17

CSS（Cascading Style Sheets）负责网页的外观与布局。理解「选择器 → 声明」的规则、优先级与盒模型，是写好样式的前提。

引入方式与优先级

引入方式写法优先级
内联样式<div style="color: red">最高（除非 !important）
内部样式<head> 中的 <style>中
外部样式<link rel="stylesheet" href="app.css">低
@importCSS 内引入其它 CSS最低（已不推荐）
/* 外部样式表 app.css */
p {
  color: #333;
  font-size: 14px;
}

选择器优先级计算：内联 > ID > 类/伪类/属性 > 标签/伪元素。权重按 (a, b, c) 累加：ID 记 (1,0,0)，类记 (0,1,0)，标签记 (0,0,1)。!important 覆盖一切，尽量少用。

常用选择器

/* 标签 / 类 / ID */
p { } .nav { } #app { }

/* 后代、子代、相邻兄弟、通用兄弟 */
div p    /* div 内所有 p（任意层级） */
div > p  /* div 的直属 p */
h1 + p   /* h1 后面紧邻的 p */
h1 ~ p   /* h1 后面所有 p */

/* 属性 / 伪类 / 伪元素 */
input[type="text"] { }      /* 属性选择器 */
a:hover { } input:focus { } /* 状态伪类 */
li:first-child { } li:nth-child(2n) { }  /* 结构伪类 */
p::before { } p::after { }  /* 伪元素，常配合 content 做图标/装饰 */

盒模型

每个元素都是一个矩形盒子，从内到外依次是 content → padding → border → margin（内容的宽高）。

┌────────────── margin ──────────────┐
│  ┌────────── border ──────────┐    │
│  │  ┌────── padding ──────┐   │    │
│  │  │   content 内容区    │   │    │
│  │  └─────────────────────┘   │    │
│  └────────────────────────────┘    │
└────────────────────────────────────┘
.box {
  width: 200px;             /* content 宽度 */
  padding: 10px;            /* 内边距，内容与边框的间距 */
  border: 1px solid #333;   /* 边框，占用盒子尺寸 */
  margin: 20px;             /* 外边距，与其他盒子的间距 */
  box-sizing: border-box;   /* 见下 */
}

box-sizing

  • content-box（默认）：width 只指内容区，padding/border 会叠加，实际占位更大。
  • border-box：width 包含 padding 和 border，总宽度即 width，布局更好预测。

实际开发几乎都设 box-sizing: border-box：

* {
  box-sizing: border-box;
}

margin 不属于盒子尺寸的一部分，始终在 border 之外。

背景与渐变

.card {
  background-color: #f5f5f5;
  background-image: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  background-size: cover;   /* 背景图等比例铺满 */
  background-position: center;
}

常见单位

单位说明
px像素，固定尺寸
em相对 父元素 字号
rem相对 根元素（html） 字号，常用于全局字号体系
%相对父容器的百分比（宽度/高度含义不同）
vw / vh相对视口宽度/高度
line-height: 1.5无单位，相对自身字号

层叠、继承与重置

  • 层叠：多条规则命中同一元素时，按「重要程度 + 优先级 + 书写顺序」裁决，后者覆盖前者。
  • 继承：颜色、字号等文本类属性会继承给子元素；盒模型相关属性（margin/padding/border 等）不继承。
  • 重置：浏览器默认样式各不相同，可用 * { margin: 0; padding: 0 } 或 CSS Reset / Preflight 抹平差异，再按需设值。

与 SCSS 的关系

CSS 本身不带变量、嵌套、mixin。SCSS 是预处理器，编译后输出普通 CSS，能大幅提升维护性。第四阶段 Vite 笔记会介绍如何集成；1.6-CSS常用样式 里有可直接复用的 SCSS 片段。
