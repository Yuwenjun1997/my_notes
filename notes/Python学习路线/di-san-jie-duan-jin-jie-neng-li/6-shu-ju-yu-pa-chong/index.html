一、数据采集基础

3.6.1 HTTP 请求库

采集流程：发送请求 → 获取响应 → 解析提取 → 清洗存储。

库特点适用场景
urllib标准库内置极简需求
requests简单易用、生态成熟同步采集首选
httpx支持同步/异步、HTTP/2异步采集、现代项目
aiohttp异步、高性能大规模并发采集

requests 使用：

import requests

# GET 请求
resp = requests.get("https://example.com", timeout=10)
print(resp.status_code)          # 状态码
print(resp.headers.get("content-type"))
print(resp.encoding)             # 编码

# 自定义请求头（模拟浏览器）
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...",
    "Accept-Language": "zh-CN,zh;q=0.9",
}
resp = requests.get(url, headers=headers, timeout=10)

# POST + JSON
resp = requests.post("https://api.example.com/login",
                     json={"username": "admin", "password": "xxx"},
                     timeout=10)

# 会话保持 Cookie（登录状态）
with requests.Session() as s:
    s.post("https://example.com/login", data={...})
    resp = s.get("https://example.com/profile")  # 自动携带 Cookie

httpx 异步采集：

import asyncio
import httpx

async def fetch_all(urls: list[str]) -> list:
    async with httpx.AsyncClient(timeout=10, follow_redirects=True) as client:
        # 并发请求多个 URL
        tasks = [client.get(url) for url in urls]
        responses = await asyncio.gather(*tasks)
        return [r.json() for r in responses if r.status_code == 200]

async def main():
    urls = [f"https://api.example.com/page/{i}" for i in range(10)]
    data = await fetch_all(urls)
    print(f"成功获取 {len(data)} 个页面")

asyncio.run(main())

异常处理与重试：

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

# ✅ 自动重试：网络错误 + 5xx + 429
retry = Retry(
    total=3,                        # 最多重试 3 次
    backoff_factor=1,               # 退避时间 1,2,4 秒
    status_forcelist=[500, 502, 503, 429],
)
adapter = HTTPAdapter(max_retries=retry)

session = requests.Session()
session.mount("https://", adapter)
session.mount("http://", adapter)

try:
    resp = session.get(url, timeout=10)
    resp.raise_for_status()         # 非 2xx 抛异常
except requests.exceptions.Timeout:
    print("请求超时")
except requests.exceptions.ConnectionError:
    print("连接失败")
except requests.exceptions.HTTPError:
    print(f"HTTP 错误：{resp.status_code}")

lxml XPath 解析：

from lxml import etree

html = etree.HTML(raw_html)                     # 解析 HTML
# XPath 定位
titles = html.xpath("//div[@class='article']//h2/text()")
links = html.xpath("//div[@class='article']/a/@href")

# 常用 XPath
# //div                 所有 div
# //div[@class="x"]     class 为 x 的 div
# //a/@href             a 的 href 属性
# text()                节点文本
# ../../../              向上回溯

CSS 选择器 vs XPath：

需求CSSXPath
class 选择.desc//*[@class="desc"]
id 选择#main//*[@id="main"]
属性存在[data-id]//*[@data-id]
文本包含:contains()(非标准)//p[contains(text(),"词")]

3.6.3 Selenium 与 Playwright

动态页面：内容由 JavaScript 渲染，普通 requests 拿不到数据。

方案优点缺点

Playwright 入门：

pip install playwright
playwright install chromium    # 安装浏览器
import asyncio
from playwright.async_api import async_playwright

async def scrape_dynamic(url: str):
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()

        # ✅ 智能等待：等待元素出现（自动处理渲染时序）
        await page.goto(url, wait_until="networkidle")
        await page.wait_for_selector(".product-list")

        # 提取数据
        items = await page.query_selector_all(".product")
        for item in items[:5]:
            title = await item.query_selector(".name")
            print(await title.inner_text())

        # 执行 JS 获取数据
        data = await page.evaluate("() => window.__INITIAL_STATE__")
        await browser.close()

asyncio.run(scrape_dynamic("https://example.com/list"))

Playwright 常用操作：

# 表单交互

page.on("response", handle_response)

四、反爬与合规

3.6.4 常见反爬与应对

常见反爬手段：

反爬手段表现应对策略
UA 检测拒绝非浏览器 UA伪装真实浏览器 UA
频率限制请求过多封 IP限速、代理池
IP 封禁短时间大量请求代理 IP、分布式
JS 渲染数据由 JS 生成Playwright 渲染
验证码登录/查询需验证码识别或人工（谨慎）
请求签名参数需加密签名逆向 JS（有合规风险）

降低被反爬概率的规范做法：

import requests
import time
from random import uniform

headers = {
    "User-Agent": "Mozilla/5.0 ...",
    "Referer": "https://example.com/",
}

for i in range(100):
    resp = requests.get(f"{url}/{i}", headers=headers, timeout=10)
    # ✅ 遵守道德爬虫：随机间隔，控制频率
    time.sleep(uniform(0.5, 1.5))

    # 频率控制：批量请求时统一限速
    if i % 10 == 0:
        time.sleep(3)

3.6.5 爬虫合规红线

道德与法律约束：

原则说明
遵守 robots.txt读取并遵循网站的爬虫协议
控制请求频率不冲击对方服务器
尊重版权不爬取并分发受版权保护的内容
个人数据遵守《个人信息保护法》等法规
不绕过技术保护不破解登录、验证码、加密

def clean_data(df):
    # 1. 去重
    df = df.drop_duplicates(subset=["url"])

    # 2. 去除空白字符
    df["title"] = df["title"].str.strip()

    # 3. 类型转换
    df["views"] = pd.to_numeric(df["views"], errors="coerce")

    # 4. 清洗异常值
    df = df[df["views"] >= 0]

    # 5. 处理缺失
    df = df.fillna({"views": 0, "category": "未分类"})
    return df

import requests
import pandas as pd
from bs4 import BeautifulSoup

def scrape_news(url):
    resp = requests.get(url, timeout=10)
    soup = BeautifulSoup(resp.text, "lxml")

    records = []
    for item in soup.select(".news-item"):
        records.append({
            "title": item.select_one(".title").text.strip(),
            "date": item.select_one(".date").text.strip(),
            "link": item.find("a")["href"],
        })
    return pd.DataFrame(records)

def main():
    df = scrape_news("https://example.com/news")
    df["date"] = pd.to_datetime(df["date"])
    daily_count = df.groupby(df["date"].dt.date).size()
    daily_count.plot(kind="line", title="每日新闻数量")
    df.to_csv("news.csv", index=False, encoding="utf-8-sig")

if __name__ == "__main__":
    main()

目标

  5. 用 matplotlib 生成柱状图与折线图报告
  6. 导出 CSV（UTF-8-BOM）与 Excel 结果
