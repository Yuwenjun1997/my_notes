一、FastAPI 概览

1.1 FastAPI 定位与优势

FastAPI 是一个基于 Python 3.7+ 的现代 Web 框架，建立在两大核心之上：

  • Starlette：轻量级 ASGI 框架，提供路由、中间件、WebSocket 等 Web 基础能力
  • Pydantic：数据校验库，提供类型安全的请求/响应模型

核心特性

特性说明
高性能基于异步 ASGI，接近 Node.js 的性能
自动文档自动生成 Swagger UI 和 ReDoc 交互式文档
类型安全基于 Python 类型注解做校验，IDE 智能提示友好
依赖注入内置 Depends，实现解耦与复用
异步原生原生支持 async/await
代码简洁声明式定义 API，样板代码少

安装

pip install "fastapi[standard]"
# 说明：[standard] 会安装 uvicorn、httpx 等常用依赖

Hello World

from fastapi import FastAPI

app = FastAPI(title="我的 API")

@app.get("/")
async def root():

二、路由与参数

2.1 路径参数与查询参数

路径参数：URL 中的动态片段，用 {参数名} 声明。

from fastapi import FastAPI, Path

app = FastAPI()

@app.get("/users/{user_id}")
async def get_user(
    user_id: int = Path(gt=0),          # 路径参数，必须为正整数
):
    return {"user_id": user_id}

@app.get("/articles/{article_id}/comments/{comment_id}")
async def get_comment(article_id: int, comment_id: int):
    # 多个路径参数
    return {"article": article_id, "comment": comment_id}

查询参数：URL 中 ?key=value 部分，函数参数默认值即为可选。

from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/search")
async def search(
    q: str,                                  # 必填查询参数
    page: int = 1,                           # 可选，默认 1
    page_size: int = Query(default=10, le=100),  # 可选，带约束（最大 100）
    sort: str | None = None,                 # 可选，可为空
):
    return {"q": q, "page": page, "page_size": page_size, "sort": sort}

# 请求示例：
# GET /search?q=python&page=2&sort=asc

2.2 请求体（Body）

请求体：用 Pydantic 模型声明，自动完成 JSON 解析与校验。

from pydantic import BaseModel, Field

class UserCreate(BaseModel):
    name: str = Field(min_length=2, max_length=50)   # 长度约束
    age: int = Field(ge=0, le=150)                   # 范围约束
    email: str | None = None                         # 可选字段

@app.post("/users")
async def create_user(user: UserCreate):
    # user 已自动完成校验，可直接使用
    return {"id": 1, **user.model_dump()}

2.3 Header 与 Cookie

from fastapi import FastAPI, Header, Cookie

app = FastAPI()

@app.get("/info")
async def get_info(
    user_agent: str | None = Header(default=None),   # 读取请求头
    token: str | None = Cookie(default=None),        # 读取 Cookie
):
    return {"user_agent": user_agent, "token": token}

@app.get("/token")
async def set_token():
    from fastapi import Response
    response = Response("ok")
    response.set_cookie(key="token", value="abc123", httponly=True, max_age=3600)
    return response

2.4 Request 对象

当需要访问原始请求信息时，可以注入 Request 对象。

from fastapi import FastAPI, Request

app = FastAPI()

@app.get("/raw")
async def raw(request: Request):
    return {
        "method": request.method,
        "url": str(request.url),
        "headers": dict(request.headers),
        "client": request.client.host if request.client else None,
        "body": await request.body(),          # 原始请求体
    }

三、Pydantic 校验

3.1 字段校验

Pydantic 在 FastAPI 中承担所有数据模型的定义与校验。

from pydantic import BaseModel, Field, EmailStr, field_validator

class User(BaseModel):
    username: str = Field(min_length=3, pattern=r"^[a-zA-Z0-9_]+$")
    age: int = Field(ge=0, le=120)
    email: EmailStr                              # 邮箱格式校验
    tags: list[str] = []                         # 列表，默认空

    # 自定义校验器
    @field_validator("username")
    @classmethod
    def check_username(cls, v: str):
        if v == "admin":
            raise ValueError("用户名不能为 admin")
        return v

3.2 嵌套模型

from pydantic import BaseModel

class Address(BaseModel):
    city: str
    street: str

class User(BaseModel):
    name: str
    address: Address        # 嵌套模型
    friends: list["User"] | None = None  # 自引用（需字符串引号）

3.3 response_model 输出过滤

response_model 控制响应结构，自动过滤掉多余字段，同时生成 OpenAPI 文档。

from pydantic import BaseModel, ConfigDict

class UserIn(BaseModel):
    username: str
    password: str          # 内部字段

class UserOut(BaseModel):
    username: str          # 对外只暴露该字段
    model_config = ConfigDict(from_attributes=True)  # 允许从 ORM 对象转换

@app.post("/users", response_model=UserOut)
async def create_user(user: UserIn):
    # 内部返回完整对象，FastAPI 自动按 UserOut 过滤
    return {"username": user.username, "password": user.password}

关键点：response_model 还能自动做字段约束（如 ge）、别名转换，并过滤多余数据防止敏感信息泄露。

四、依赖注入

4.1 Depends 基础

依赖注入（DI） 让函数参数在调用前自动被解析注入，用于共享逻辑、复用代码。

from fastapi import FastAPI, Depends, HTTPException

app = FastAPI()

# 依赖函数：校验 token
def verify_token(token: str | None = None):
    if token != "secret-token":
        raise HTTPException(status_code=401, detail="无效的 token")
    return {"user": "zhangsan"}

@app.get("/profile")
async def profile(user: dict = Depends(verify_token)):
    # user 由 verify_token 的返回值注入
    return {"message": f"欢迎 {user['user']}"}

4.2 依赖的依赖（子依赖）

def check_db():
    return {"db": "connected"}

def get_current_user(db: dict = Depends(check_db)):
    return {"user_id": 1, "db": db}

@app.get("/users/me")
async def read_me(current_user: dict = Depends(get_current_user)):
    # get_current_user 内部的 check_db 会自动先执行
    return current_user

4.3 类依赖与全局依赖

类依赖：将依赖封装为类，逻辑更清晰。

from fastapi import FastAPI, Depends

app = FastAPI()

class CommonDeps:
    def __init__(self):
        self.db_name = "main_db"

    def __call__(self):
        return {"db_name": self.db_name}

@app.get("/items")
async def read_items(common: dict = Depends(CommonDeps())):
    return common

全局依赖：所有路由自动生效。

from fastapi import FastAPI, Depends

def add_timestamp():
    return {"started": True}

app = FastAPI(dependencies=[Depends(add_timestamp)])  # 全局依赖

4.4 异步依赖

依赖函数同样支持 async，FastAPI 会自动等待。

import httpx
from fastapi import FastAPI, Depends

app = FastAPI()

async def get_weather():
    async with httpx.AsyncClient() as client:
        resp = await client.get("https://httpbin.org/anything")
        return resp.json()

@app.get("/weather")
async def weather(data: dict = Depends(get_weather)):
    return data

五、错误处理

5.1 HTTPException

HTTPException 用于返回带状态码的错误响应。

from fastapi import FastAPI, HTTPException

app = FastAPI()

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id <= 0:
        raise HTTPException(
            status_code=400,
            detail="item_id 必须为正数",
            headers={"X-Error": "invalid-id"},   # 可自定义响应头
        )
    if item_id == 404:
        raise HTTPException(status_code=404, detail="资源不存在")
    return {"item_id": item_id}

5.2 自定义异常处理器

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

class BizError(Exception):
    def __init__(self, code: int, message: str):
        self.code = code
        self.message = message

app = FastAPI()

@app.exception_handler(BizError)
async def biz_error_handler(request: Request, exc: BizError):
    return JSONResponse(
        status_code=400,
        content={"code": exc.code, "message": exc.message},
    )

@app.get("/biz")
async def biz():
    raise BizError(code=1001, message="业务规则校验失败")

常用异常处理器

异常默认响应说明

StarletteHTTPException按状态码底层 HTTP 异常
自定义异常自定义业务层统一错误

六、中间件与生命周期

6.1 中间件

中间件 在请求进入路由前、响应返回前执行，用于日志、鉴权、CORS 等。

import time
from fastapi import FastAPI, Request

app = FastAPI()

@app.middleware("http")
async def log_requests(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)     # 调用下一个中间件/路由
    duration = time.perf_counter() - start
    response.headers["X-Process-Time"] = f"{duration:.4f}s"
    return response

6.2 CORS

CORS（跨域资源共享） 控制浏览器跨域访问权限，前后端分离项目必须配置。

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],   # 允许的前端域名
    allow_credentials=True,
    allow_methods=["*"],                       # 允许的方法
    allow_headers=["*"],                       # 允许的请求头
)

# ❌ 生产环境用 * 放行所有来源，存在安全风险

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],    # ❌ 生产环境不要全放行
    allow_credentials=True, # ❌ 与 * 同时使用会触发浏览器报错
)

6.3 生命周期（lifespan）

生命周期 管理应用启动/关闭时的资源（连接池、预热缓存等）。

from contextlib import asynccontextmanager
from fastapi import FastAPI

@asynccontextmanager
async def lifespan(app: FastAPI):
    # 启动前：创建资源
    print("应用启动，初始化资源...")
    app.state.redis = {"connected": True}   # 挂载到 app.state
    yield
    # 关闭后：清理资源
    print("应用关闭，清理资源...")

app = FastAPI(lifespan=lifespan)

@app.get("/health")
async def health():
    return {"redis": app.state.redis}

七、自动文档

7.1 Swagger UI 与 ReDoc

FastAPI 基于 OpenAPI 规范自动生成接口文档，无需额外配置。

文档地址特点
Swagger UI/docs交互式，可直接测试接口
ReDoc/redoc排版精美，适合分享
OpenAPI JSON/openapi.json机器可读，可生成 SDK

7.2 文档定制

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI(
    title="电商 API",
    description="电商平台后端接口文档",
    version="1.0.0",
    docs_url="/docs",        # 自定义 Swagger 地址
    redoc_url=None,          # 禁用 ReDoc
)

class Item(BaseModel):
    name: str
    price: float

@app.post(
    "/items",
    summary="创建商品",          # 文档中的摘要
    description="创建一条新的商品记录",  # 文档中的详细说明
    tags=["items"],               # 文档分组
    response_description="创建成功",
)
async def create_item(item: Item):
    """创建商品（docstring 也会进入文档）"""
    return item

# app/main.py
from fastapi import FastAPI, HTTPException, Depends
from pydantic import BaseModel, Field

app = FastAPI(title="Todo API")

class Todo(BaseModel):
    title: str = Field(min_length=1, max_length=100)
    done: bool = False
    priority: int = Field(default=1, ge=1, le=5)

# 简单内存存储
todos: dict[int, Todo] = {}
next_id = 1

@app.post("/todos", status_code=201)
async def create_todo(todo: Todo):
    global next_id
    todos[next_id] = todo
    result = {"id": next_id, **todo.model_dump()}
    next_id += 1
    return result

@app.get("/todos")
async def list_todos():
    return [{"id": i, **t.model_dump()} for i, t in todos.items()]

@app.get("/todos/{todo_id}")
async def get_todo(todo_id: int):
    if todo_id not in todos:
        raise HTTPException(status_code=404, detail="待办事项不存在")
    return {"id": todo_id, **todos[todo_id].model_dump()}

@app.delete("/todos/{todo_id}", status_code=204)
async def delete_todo(todo_id: int):
    todos.pop(todo_id, None)
