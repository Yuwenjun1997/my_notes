一、动态页面与浏览器自动化

2.1 为什么需要浏览器自动化

很多现代网站的数据由 JavaScript 异步渲染生成，直接请求 HTML 拿不到内容。判断方式：

# ❌ 直接用 requests 拿不到动态数据
import requests
resp = requests.get("https://example.com/spa")
# 页面里没有目标数据，因为数据是 JS 之后渲染的

# ✅ 方案一：先分析 XHR/API，直接请求后端接口
api_url = "https://example.com/api/books?page=1"
data = requests.get(api_url).json()

# ✅ 方案二：用浏览器自动化模拟真实浏览器渲染（见下文 Playwright）

技术选型：数据能否从接口拿到，优先走接口（更快更稳）；拿不到才用浏览器自动化。

2.2 Playwright 核心操作

Playwright 是现代浏览器自动化库，支持 Chromium / Firefox / WebKit，提供自动等待与网络拦截能力。

pip install playwright
playwright install chromium    # 安装浏览器内核

页面访问与元素定位

import asyncio
from playwright.async_api import async_playwright


async def scrape_dynamic():
    async with async_playwright() as p:
        # 启动浏览器（headless 无头模式）
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()

        # 访问页面（wait_until='networkidle' 等网络空闲）
        await page.goto("https://example.com", wait_until="networkidle")

        # 等待元素出现：比固定 sleep 更可靠
        await page.wait_for_selector(".product-item", timeout=5000)

        # 定位元素：支持 CSS / XPath / 文本
        titles = await page.locator(".product-title").all_text_contents()
        prices = await page.locator(".price").all_text_contents()

        # 点击"加载更多"按钮触发懒加载
        load_more = page.locator("button:has-text('加载更多')")
        if await load_more.count():
            await load_more.click()

        # 滚动到底部触发滚动加载
        await page.mouse.wheel(0, 10000)
        await page.wait_for_timeout(1000)

        await browser.close()
        return titles, prices

网络拦截与数据捕获

async def capture_api():
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()

        # 捕获所有 XHR/API 响应，直接拿 JSON
        async def on_response(response):
            if "/api/" in response.url and "json" in response.headers.get("content-type", ""):
                try:
                    data = await response.json()
                    print(response.url, data[:2])   # 打印接口数据
                except Exception:
                    pass

        page.on("response", on_response)
        await page.goto("https://example.com")
        await page.wait_for_timeout(3000)
        await browser.close()

二、Selenium 与 Playwright 深入对比

2.3 两者差异与选型

维度SeleniumPlaywright
浏览器支持Chrome/Firefox/Safari/EdgeChromium/Firefox/WebKit
安装需要 WebDriver内置驱动，playwright install 即可
自动等待需显式 WebDriverWait内置自动等待，默认开启
并发能力较弱Context 隔离，天然支持并发
网络拦截弱（需代理/插件）内置 page.on("request"/"response")
反爬指纹特征较明显（navigator.webdriver=true）可配置 stealth，指纹更接近真实
维护活跃度一般非常活跃（微软维护）
API 风格同步为主，可异步同步/异步双 API

新项目建议优先 Playwright：自动等待 + 网络拦截 + 并发隔离三个核心能力开箱即用。

2.4 浏览器指纹与反检测

网站通过 JS 检测 navigator.webdriver、User-Agent、Canvas/WebGL 指纹等识别自动化。降低被识别概率的做法：

from playwright.async_api import async_playwright


async def stealth_scrape():
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)

        # 注入 stealth 脚本，抹除自动化特征
        stealth_js = """
        Object.defineProperty(navigator, 'webdriver', { get: () => undefined });
        window.chrome = { runtime: {} };
        Object.defineProperty(navigator, 'languages', { get: () => ['zh-CN', 'zh'] });
        Object.defineProperty(navigator, 'plugins', {
            get: () => [1, 2, 3, 4, 5],
        });
        """
        context = await browser.new_context(
            user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120.0.0.0 Safari/537.36",
            viewport={"width": 1920, "height": 1080},
            locale="zh-CN",
            timezone_id="Asia/Shanghai",
        )
        await context.add_init_script(stealth_js)  # 在每个页面加载前执行

        page = await context.new_page()
        await page.goto("https://example.com")
        # 模拟真实用户行为：移动鼠标、偶尔滚动
        await page.mouse.move(500, 300)
        await page.wait_for_timeout(800)
        await browser.close()

重要合规提醒：反检测技术仅应用于已获授权的站点（如自有系统、公开 API、已同意采集的数据源）。强行突破验证码、绕过付费墙、抓取非公开数据可能违反服务条款与法律。

三、反爬对抗与合规策略

2.5 代理池与 IP 轮换

高频请求容易触发网站封 IP，常见应对是用代理池分散请求。

# 代理中间件思路（配合 requests/httpx）
import random
import httpx

PROXY_POOL = [
    "http://user:pass@proxy1.example.com:8080",
    "http://user:pass@proxy2.example.com:8080",
    "http://user:pass@proxy3.example.com:8080",
]


def fetch_with_proxy(url):
    """每次请求随机挑选一个代理，失败则换下一个"""
    for _ in range(len(PROXY_POOL)):
        proxy = random.choice(PROXY_POOL)
        try:
            resp = httpx.get(url, proxy=proxy, timeout=10)
            if resp.status_code == 200:
                return resp
        except httpx.ProxyError:
            continue  # 该代理失效，换下一个
    raise RuntimeError("所有代理均失败")

代理使用规范

事项建议
请求频率加 DOWNLOAD_DELAY / time.sleep 随机延迟
失败重试限制重试次数，避免放大流量
合规性使用正规代理服务，遵守目标站点服务条款
数据范围只采集公开、合法、非敏感数据

2.6 频率控制与限速

节流是最基础也最重要的反封禁手段：

import time
import random


class RateLimiter:
    """简单限速器：控制每秒最大请求数"""

    def __init__(self, max_qps=2.0):
        self.max_qps = max_qps
        self.min_interval = 1.0 / max_qps
        self.last_request = 0.0

    def wait(self):
        # 距离上次请求不足最小间隔则等待
        now = time.monotonic()
        gap = self.last_request + self.min_interval - now
        if gap > 0:
            # 加上随机抖动，模拟人类节奏
            time.sleep(gap + random.uniform(0.1, 0.3))
        self.last_request = time.monotonic()


limiter = RateLimiter(max_qps=1.5)
for url in url_list:
    limiter.wait()
    resp = httpx.get(url)

if resp.status_code == 429:

四、合规与数据安全红线

2.8 爬虫的合规边界

采集数据前必须明确以下边界，违反可能承担法律责任：

  1. robots.txt：尊重目标站的爬虫协议，禁用声明不可爬取的路径
  2. 服务条款（ToS）：采集行为不得违反目标站点的使用条款
  3. 个人隐私：不采集、不存储身份证号、手机号等敏感个人信息
  4. 版权数据：不抓取受版权保护的付费内容（影视、书籍、音乐）
  5. 访问压力：控制频率，不得对目标服务器造成拒绝服务
# 尊重 robots.txt 的简单判断
import urllib.robotparser

rp = urllib.robotparser.RobotFileParser()
rp.set_url("https://example.com/robots.txt")
rp.read()

if rp.can_fetch("*", "https://example.com/private"):
    print("允许爬取")
else:
    print("robots.txt 禁止该路径，跳过")

2.9 数据清洗与存储安全

import re


def sanitize(item):
    """采集后的数据清洗与脱敏"""
    # 去除 HTML 标签
    item["content"] = re.sub(r"<[^>]+>", "", item.get("content", ""))
    # 去除首尾空白
    item["title"] = item.get("title", "").strip()
    # 手机号脱敏：138****1234
    item["phone"] = re.sub(r"(\d{3})\d{4}(\d{4})", r"\1****\2", item.get("phone", ""))
    # 只保留合法字段，丢弃多余数据
    allowed = {"title", "content", "phone"}
    return {k: v for k, v in item.items() if k in allowed}

五、实践项目

项目目标

用 Playwright 爬取一个需要滚动加载的动态网站（如电商列表页），捕获其 XHR 接口数据，并配合限速与代理策略完成合规采集，输出 CSV。

步骤：

  1. 分析目标站点：确认是动态渲染还是 API 直出，优先找 XHR 接口
  2. 用 Playwright 的 page.on("response") 捕获接口 JSON
  3. 实现 RateLimiter 控制请求频率，配置代理池
  4. 处理滚动加载与"加载更多"按钮，拉取全部分页数据
  5. 检查 robots.txt，确认采集合法
  6. 数据清洗后写入 CSV，统计采集总量
