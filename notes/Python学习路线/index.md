## 📘 第一阶段：Python 基础

> **学习周期**：3-4 周 | **每日建议**：2-3 小时
> **目标**：掌握 Python 语言核心语法、标准库与虚拟环境管理，能独立搭建开发环境并编写模块化程序。

| 模块 | 核心内容 | 文档 |
|:-----|:---------|:----:|
| **1.1 环境搭建与工具链** | 版本选择（3.11/3.12）、解释器与 REPL、VS Code / Jupyter / PyCharm 对比、pyenv 多版本管理、pip 镜像源、ruff / black 代码质量工具 | [📖 查看](./第一阶段-Python基础/1.1-环境搭建与工具链.md) |
| **1.2 语法核心** | 数据类型与动态类型、流程控制（if/for/while/match-case）、容器 list/tuple/dict/set、切片与解包、推导式、F-string 格式规范、异常处理（raise from、自定义异常） | [📖 查看](./第一阶段-Python基础/1.2-语法核心.md) |
| **1.3 函数模块与面向对象** | 函数参数（\*args/\*\*kwargs）、LEGB 闭包、装饰器、迭代器与生成器、import 机制、类与对象、MRO/super、魔法方法、abc 抽象基类、dataclasses 数据类 | [📖 查看](./第一阶段-Python基础/1.3-函数模块与面向对象.md) |

> **学习周期**：1-2 个月 | **每日建议**：2-3 小时
> **目标**：掌握以 FastAPI 为主的 Web 开发全链路（网络异步、ORM 数据库、API 设计），了解 Django 生态。

| 模块 | 核心内容 | 文档 |

| **2.1 网络编程与异步基础** | HTTP 协议复习、requests/httpx 请求库、socket 编程、asyncio 核心（async/await/Task）、aiohttp、同步 vs 异步对比、ASGI 与 uvicorn | [📖 查看](./第二阶段-Web开发/2.1-网络编程与异步基础.md) |
| **2.2 FastAPI 详解** | Starlette + Pydantic 架构、路由与参数、Pydantic 校验与 response\_model、依赖注入 Depends、错误处理、中间件与 CORS、生命周期、Swagger 自动文档 | [📖 查看](./第二阶段-Web开发/2.2-FastAPI详解.md) |
| **2.3 Django 基础与对比** | MTV 架构、Model 与 ORM、迁移、FBV/CBV、Admin 后台、DRF 基础、Django vs FastAPI 对比选型 | [📖 查看](./第二阶段-Web开发/2.3-Django基础与对比.md) |

| **3.3 任务队列与定时任务** | Celery 核心（Broker/Worker/结果后端）、retry/rate\_limit、FastAPI 集成、APScheduler 调度器、Celery vs APScheduler 对比、幂等与死信 | [📖 查看](./第三阶段-进阶能力/3.3-任务队列与定时任务.md) |

## 🗺️ 学习路线总览

### 阶段规划

| 阶段 | 时间 | 每日学习 | 核心内容 |
|:----|:----|:--------:|:---------|
| 第一阶段：Python 基础 | 3-4 周 | 2-3 小时 | 环境工具、语法、函数/OOP、标准库、虚拟环境 |
| 第二阶段：Web 开发 | 1-2 个月 | 2-3 小时 | 网络异步、FastAPI、Django、ORM、API 设计 |
| 第三阶段：进阶能力 | 2 个月 | 3-4 小时 | 并发异步、Redis、任务队列、pytest、安全、数据爬虫 |
| 第四阶段：分布式与部署 | 1-2 个月 | 3-4 小时 | 微服务/消息、Docker、可观测性、性能优化 |
| 深度学习（并行） | 持续 | 2-3 小时 | 异步深入、数据爬虫、微服务、DevOps、AI 应用 |

### 学习建议

| 时间段 | 内容 | 时长 |
|:------|:-----|:----:|
| 🌅 早上 | 理论 / 文档与源码阅读（语法、框架、协议） | 1-1.5h |
| 🌤️ 下午 | 实践 / 写代码 + 完成模块末尾实践项目 | 2h |
| 🌙 晚上 | 复盘总结 + 查阅速查手册 / 整理笔记 | 1h |

### 项目驱动学习

每个阶段都配有**实践项目**，建议按以下方式使用：

1. **先学理论**：阅读对应模块的文档，理解核心概念
2. **动手实践**：完成文档末尾的实践项目
3. **复盘总结**：将遇到的问题和解决方案记录下来
4. **深入拓展**：对照深度学习方向进行进阶探索，随手查阅开发速查手册

***

> 💡 **学习小贴士**：知识体系是立体的，建议在完成第一阶段后，将深度学习方向的 **02-数据与爬虫** 与主线并行推进；对 AI 应用感兴趣的，可同步接入 **05-AI 应用与工程化**。
