## 📘 第一阶段：核心基础

> **学习周期**：1-2 个月 | **每日建议**：3-4 小时\
> **目标**：掌握 Java 后端开发的核心基础能力，熟悉构建工具、数据库基础、网络与 HTTP 协议。

| 模块 | 核心内容 | 文档 |
|:-----|:---------|:----:|
| **1.1 构建工具 & 项目管理** | Maven 依赖管理、生命周期、多模块配置；Gradle 基础语法、任务执行、Wrapper；Maven vs Gradle 对比 | [📖 查看](./第一阶段-核心基础/1.1-构建工具与项目管理.md) |
| **1.2 数据库基础** | SQL JOIN、索引（B+ 树）、事务（ACID、隔离级别、MVCC）、锁；JDBC 原理；HikariCP 连接池 | [📖 查看](./第一阶段-核心基础/1.2-数据库基础.md) |
| **1.3 网络 & HTTP** | HTTP/1.1 请求方法、状态码、缓存机制；RESTful API 设计规范；Cookie 与 Session；语义化 URL | [📖 查看](./第一阶段-核心基础/1.3-网络与HTTP.md) |

## 🚀 第二阶段：主流框架

> **学习周期**：2-3 个月 | **每日建议**：3-4 小时\
> **目标**：掌握 Spring 全家桶核心知识，熟悉 Spring Boot 自动配置原理和 ORM 实现。

| 模块 | 核心内容 | 文档 |
|:-----|:---------|:----:|
| **2.1 Spring 全家桶** | IoC 容器 & DI、AOP 面向切面编程、Bean 生命周期；Spring MVC DispatcherServlet 流程、请求处理；Spring Boot 自动配置原理、Starter、Actuator；Spring Data JPA & MyBatis ORM 框架 | [📖 查看](./第二阶段-主流框架/2.1-Spring全家桶.md) |
| **2.2 Starter 配置指南** | Web / JDBC / JPA / MyBatis / Security / Cache / Redis / RabbitMQ / Kafka 等常用 Starter 的 application.yml 配置教程，逐项解释每个配置项的作用 | [📖 查看](./第二阶段-主流框架/2.2-SpringBoot常用Starter配置.md) |
| **2.3 SSE 实时推送** | SSE 协议原理与格式；Spring MVC SseEmitter 基础用法与广播；WebFlux Flux/ServerSentEvent 响应式实现；AI 流式输出实战 | [📖 查看](./第二阶段-主流框架/2.3-SSE实时推送-SseEmitter与WebFlux.md) |

## ⚡ 第三阶段：进阶能力

> **学习周期**：2-3 个月 | **每日建议**：3-4 小时\
> **目标**：掌握缓存、消息队列、安全等核心技术，能够设计和实现高效的分布式系统。

| 模块 | 核心内容 | 文档 |
|:-----|:---------|:----:|
| **3.1 缓存** | Redis 五种数据结构（String/List/Set/Hash/ZSet）、持久化（RDB/AOF/混合）、缓存穿透/击穿/雪崩解决方案、分布式锁（Redis 自实现 & Redisson） | [📖 查看](./第三阶段-进阶能力/3.1-缓存.md) |
| **3.2 消息队列** | MQ 核心概念（异步/削峰/解耦）；RabbitMQ Exchange 四种类型、消息可靠性（Confirm/ACK/DLQ）；Kafka 分区与副本、消费者组、消息顺序性；RabbitMQ vs Kafka 对比 | [📖 查看](./第三阶段-进阶能力/3.2-消息队列.md) |
| **3.3 安全** | Spring Security 过滤器链、认证与授权；JWT 结构、生成验证与刷新机制；OAuth2 四种授权模式（授权码/密码/客户端凭证） | [📖 查看](./第三阶段-进阶能力/3.3-安全.md) |
| **3.4 定时任务** | Cron 表达式详解（6/7 位结构、特殊字符、常用模板）；Spring @Scheduled（fixedDelay/fixedRate、线程池、动态管理）；Quartz（Job/Trigger/Scheduler、JDBC 集群、监听器）；XXL-JOB 分布式调度（架构、分片、GLUE、路由策略）；Elastic-Job 入门；框架对比选型 | [📖 查看](./第三阶段-进阶能力/3.4-定时任务.md) |

## 🗺️ 学习路线总览

### 阶段规划

| 阶段 | 时间 | 每日学习 | 核心内容 |
|:----|:----|:--------:|:---------|
| 第一阶段：核心基础 | 1-2 个月 | 3-4 小时 | 构建工具、数据库基础、HTTP 协议 |
| 第二阶段：主流框架 | 2-3 个月 | 3-4 小时 | Spring 全家桶、ORM 框架 |
| 第三阶段：进阶能力 | 2-3 个月 | 3-4 小时 | 缓存、消息队列、安全、定时任务 |
| 第四阶段：分布式设计 | 3 个月+ | 4-5 小时 | 微服务架构、可观测性、数据库进阶 |
| 深度学习（并行） | 持续 | 2-3 小时 | 并发编程、微服务深入、电商实战、运维、架构 |

### 学习建议

| 时间段 | 内容 | 时长 |
|:------|:-----|:----:|
| 🌅 早上 | 理论 / 源码阅读（并发、JVM、设计模式） | 1-1.5h |
| 🌤️ 下午 | 实践 / 项目（写代码 + 调试） | 2h |
| 🌙 晚上 | 总结 + 系统设计（整理笔记 + 刷题） | 1h |

### 项目驱动学习

每个阶段都配有**实践项目**，建议按以下方式使用：

1. **先学理论**：阅读对应模块的文档，理解核心概念
2. **动手实践**：完成文档末尾的实践项目
3. **复盘总结**：将遇到的问题和解决方案记录下来
4. **深入拓展**：对照深度学习方向进行进阶探索

***

> 💡 **学习小贴士**：知识体系是立体的，建议在完成第一阶段后，将深度学习方向的 **01-并发编程与JVM** 和 **05-设计模式与架构** 与主线并行推进，相辅相成。
