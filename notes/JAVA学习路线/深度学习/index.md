## 🗺️ 学习路线建议

### 并行推进策略（推荐）

```
时间线                    方向
───── ───────────────────────────────────
第1-2周   并发编程基础    +    设计模式
第3-4周   JUC深入         +    Spring源码分析
第5-6周   JVM调优         +    DDD入门
第7-8周   Netty实战       +    Sentinel/Seata
第9-10周  电商系统设计    +    CI/CD搭建
第11-12周 秒杀系统        +    K8s部署
第13-14周 系统设计真题    +    项目整合
```

### 每日学习建议

| 时间段 | 内容 | 时长 |
|--------|------|------|
| 早上 | 理论/源码阅读（并发/JVM/设计模式） | 1-1.5h |
| 下午 | 实践/项目（写代码+调试） | 2h |
| 晚上 | 总结+系统设计（整理笔记+刷题） | 1h |
