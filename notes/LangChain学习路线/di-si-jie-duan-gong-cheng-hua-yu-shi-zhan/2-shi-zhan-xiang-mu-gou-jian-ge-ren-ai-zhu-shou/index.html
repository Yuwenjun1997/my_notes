2-实战项目-构建个人AI助手

约 1281 字大约 4 分钟

2026-08-15

前四个阶段的能力在这里合体。用一个 Deep Agents 项目，把「规划 / 文件 / 子代理 / 记忆 / Skills / 审批 / 可观测」全部用上，从 0 到 1 交付一个真实可用的"个人 AI 助手"。

一、项目目标

构建一个学习资料管理助手，它需要：

需求用的能力
帮我把散乱的笔记归档整理规划 + 文件系统
针对某主题写一份专题总结子代理（写作专家）
记住我长期偏好（如"英文缩写要解释"）Store 长期记忆
按需执行特定任务（如"代码审查"）Skills 按需加载
覆盖文件前先问过我人类审批
全程可回溯LangSmith 追踪

二、架构设计

                        ┌───────────────────────────────┐
                        │   主代理：learning-boss         │
                        │  create_deep_agent             │
                        │  规划(write_todos) 文件 审批    │
                        │  记忆(store) Skills 自定义工具  │
                        └───────────────┬───────────────┘
                     task 工具派活       │  直接读写
                        ┌───────────────┼───────────────┐
                        ▼               ▼               ▼
             ┌────────────────┐  ┌──────────────┐  ┌────────────┐
             │ writer 子代理   │  │  笔记文件    │  │ skills/    │
             │ 写作/总结专家   │  │  workspace/  │  │ code-review│
             └────────────────┘  └──────────────┘  └────────────┘

三、目录结构

ai-assistant/
├── main.py                 # 组装并启动助手
├── tools.py                # 自定义工具
├── skills/
│   └── code-review/
│       └── SKILL.md        # 代码审查技能
└── workspace/              # 助手只能操作这个目录（root_dir 边界）

四、分步实现

4.1 自定义工具（tools.py）

from langchain.tools import tool

@tool
def add_topic_tag(topic: str, tag: str) -> str:
    """给某个学习主题打标签，topic 为主题名，tag 为标签名。"""
    # 真实项目可写入数据库/文件
    return f"已为主题 [{topic}] 打上标签 [{tag}]"

4.2 代码审查技能（skills/code-review/SKILL.md）

---
name: code-review
description: Python 代码审查规范：命名、错误处理、安全性检查清单
---
# 代码审查技能
审查 Python 代码时，按以下清单逐项检查：
1. 命名是否清晰（snake_case）
2. 是否捕获了会真实发生的异常
3. 是否对外部输入做了边界校验

4.3 创建子代理（写作专家）

from deepagents import create_deep_agent

writer = create_deep_agent(
    name="writer",
    model="claude-sonnet-4-5-20250929",
    system_prompt="你是学习专题写作专家，输出结构清晰的中文专题总结。",
)

4.4 组装主代理（main.py）

import os
from deepagents import create_deep_agent
from deepagents.backends import FilesystemBackend
from langgraph.checkpoint.memory import MemorySaver
from langgraph.store.memory import InMemoryStore
from tools import add_topic_tag

os.environ["LANGSMITH_TRACING"] = "true"   # 也可放环境变量
os.environ["LANGSMITH_PROJECT"] = "learning-assistant"

agent = create_deep_agent(
    name="learning-boss",
    model="claude-sonnet-4-5-20250929",
    tools=[add_topic_tag],                              # 自定义工具
    system_prompt=(
        "你是学习资料管理助手。归档笔记时先列计划；"
        "写专题时派给 writer 子代理；覆盖文件前会停下来确认。"
    ),
    subagents=[writer],                                 # 子代理
    backend=FilesystemBackend(root_dir="./workspace", virtual_mode=False),  # 文件边界
    skills=["./skills/"],                               # 按需技能
    interrupt_on={"write_file": True},                  # 写文件要审批
    checkpointer=MemorySaver(),                         # 短时记忆/审批支撑
    store=InMemoryStore(),                              # 长时记忆
)

4.5 运行（main.py 尾部）

def chat(user_text: str, thread_id: str):
    config = {"configurable": {"thread_id": thread_id}}
    return agent.invoke(
        {"messages": [{"role": "user", "content": user_text}]},
        config=config,
    )["messages"][-1].content

if __name__ == "__main__":
    # 第一次对话：归档笔记（会触发规划 + 写文件审批）
    print(chat("把这几段学习笔记归档到 workspace，并给'并发编程'打上'重点'标签", "u-1"))
    # 人工批准后……
    print(chat("批准写入", "u-1"))
    # 长任务：派 writer 子代理写专题
    print(chat("写一份 500 字的『线程池调优』专题总结，存到 workspace", "u-2"))

⚠️ 运行提示：写文件会因 interrupt_on 被中断，等待人工"批准"——这正是我们想要的行为。批准后文件才真正落盘。

五、跑一遍看效果

pip install langchain langgraph deepagents langchain-anthropic
python main.py

预期链路（可在 LangSmith 里回放）：

u-1: 用户下达归档任务
  → write_todos（列计划）
  → add_topic_tag（打标签）
  → write_file（被审批中断，等你批准）
u-1: 用户说"批准"
  → 从断点继续 → write_file 真正落盘
u-2: 用户下达专题写作
  → write_todos → task(派给 writer) → writer 返回专题
  → write_file（再次审批） → 完成

六、扩展方向

方向怎么做
长期记忆持久化把 InMemoryStore 换成生产级持久化 Store（如 Postgres 版）
更多专家子代理再加 reviewer（审查）、search（检索）等子代理，按需注册
评估上线建 Dataset + Evaluation，每次改提示词都用分数验证（4.1 节）
技能库扩充把日常重复任务固化成 Skills，随用随加载
审批精细化从"全部 write_file 审批"收敛到"特定文件/特定操作审批"
