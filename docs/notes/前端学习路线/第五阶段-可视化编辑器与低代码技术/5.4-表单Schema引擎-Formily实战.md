# 表单 Schema 引擎：Formily 实战

## JSON Schema 表单概述

表单是低代码平台最常见的应用场景。传统表单每个字段都需要手写 JSX，而 Schema 驱动表单只需一份 JSON 描述，引擎自动渲染完整的表单 UI、校验逻辑和联动行为。

典型需求：
- 后端返回字段配置，前端动态渲染表单
- 字段间存在复杂的显隐、禁用、选项依赖关系
- 同一套 Schema 需要在多个页面复用

主流方案对比：

| 方案 | 出品方 | 特点 |
|:-----|:-------|:-----|
| **Formily** | 阿里巴巴 | 联动能力强，Schema 规范完整，适合复杂场景 |
| FormRender | 京东 | 轻量易上手，与 antd 集成好 |
| Ant Design ProForm | 蚂蚁 | 配置式 API，与 antd 深度绑定，上手最快 |

## Formily 核心概念

### 基础结构

```tsx
import { createForm } from '@formily/core';
import { FormProvider, FormConsumer, Field, useField } from '@formily/react';
import { Input, Select, DatePicker, Form } from 'antd';

// 创建表单实例
const form = createForm();

function MyForm() {
  return (
    <FormProvider form={form}>
      <Form layout="vertical">
        <Field name="username" label="用户名" component={Input} />
        <Field name="birthday" label="生日" component={DatePicker} />
      </Form>
    </FormProvider>
  );
}
```

### Schema 模式

Formily 的精髓在于用 Schema 替代 JSX 描述表单：

```tsx
import { createSchemaField } from '@formily/react';

// 注册 Schema 中使用的组件
const SchemaField = createSchemaField({
  components: {
    Input,
    Select,
    DatePicker,
    FormItem: Form.Item,
  },
});

const schema = {
  type: 'object',
  properties: {
    username: {
      type: 'string',
      title: '用户名',
      'x-decorator': 'FormItem',
      'x-component': 'Input',
      'x-component-props': { placeholder: '请输入用户名' },
      required: true,
    },
    role: {
      type: 'string',
      title: '角色',
      'x-decorator': 'FormItem',
      'x-component': 'Select',
      enum: [
        { label: '管理员', value: 'admin' },
        { label: '普通用户', value: 'user' },
      ],
    },
  },
};

function SchemaForm() {
  return (
    <FormProvider form={form}>
      <SchemaField schema={schema} />
    </FormProvider>
  );
}
```

`x-component` 指定渲染哪个组件，`x-decorator` 指定外层包裹组件（通常是 FormItem），`x-component-props` 透传组件属性。

## 联动与校验

### 字段联动（x-reactions）

```ts
const schema = {
  type: 'object',
  properties: {
    province: {
      type: 'string',
      title: '省份',
      'x-decorator': 'FormItem',
      'x-component': 'Select',
      enum: [
        { label: '浙江省', value: 'zhejiang' },
        { label: '广东省', value: 'guangdong' },
      ],
    },
    city: {
      type: 'string',
      title: '城市',
      'x-decorator': 'FormItem',
      'x-component': 'Select',
      // 联动：根据省份动态加载城市
      'x-reactions': {
        dependencies: ['province'],
        fulfill: {
          state: {
            visible: '{{$deps[0] !== undefined}}',
          },
          run: async (field) => {
            const province = field.query('province').get('value');
            const cities = await fetchCities(province);
            field.dataSource = cities.map(c => ({ label: c.name, value: c.code }));
          },
        },
      },
    },
  },
};
```

`x-reactions` 是 Formily 最强大的特性，支持：
- **状态驱动**：根据依赖字段值控制 visible / editable / required 等
- **副作用**：动态修改字段数据源、默认值、校验规则

### 校验规则

```ts
const schema = {
  type: 'object',
  properties: {
    email: {
      type: 'string',
      title: '邮箱',
      'x-decorator': 'FormItem',
      'x-component': 'Input',
      required: true,
      'x-validator': [
        { pattern: /^\w+@\w+\.\w+$/, message: '邮箱格式不正确' },
      ],
    },
    age: {
      type: 'number',
      title: '年龄',
      'x-decorator': 'FormItem',
      'x-component': 'InputNumber',
      'x-component-props': { min: 0, max: 150 },
      'x-validator': [
        { required: true, message: '请输入年龄' },
        { minimum: 18, message: '年龄不能小于18岁' },
      ],
    },
  },
};
```

## 自定义表单组件

将业务组件接入 Formily：

```tsx
// 1. 编写业务组件
function ColorPicker({ value, onChange }) {
  return (
    <div style={{ display: 'flex', gap: 8 }}>
      {['#1890ff', '#52c41a', '#faad14', '#f5222d'].map(color => (
        <div
          key={color}
          onClick={() => onChange?.(color)}
          style={{
            width: 32, height: 32, borderRadius: 4, background: color,
            border: value === color ? '3px solid #000' : '1px solid #ddd',
            cursor: 'pointer',
          }}
        />
      ))}
    </div>
  );
}

// 2. 注册到 SchemaField
const SchemaField = createSchemaField({
  components: { Input, Select, FormItem, ColorPicker },
});

// 3. 在 Schema 中使用
const schema = {
  properties: {
    themeColor: {
      title: '主题色',
      'x-decorator': 'FormItem',
      'x-component': 'ColorPicker',
    },
  },
};
```

## Formily vs 其他方案

| 维度 | Formily | FormRender | ProForm |
|:-----|:--------|:-----------|:--------|
| 联动能力 | 强（x-reactions） | 中（watch 模式） | 弱（依赖 ProForm 本身） |
| Schema 规范 | 自有扩展 Schema | JSON Schema 标准 | 非标准，配置式 |
| 学习成本 | 中高 | 低 | 低 |
| 适用场景 | 复杂表单、低代码引擎 | 中等复杂度表单 | 快速后台表单 |
| 与 antd 集成 | 解耦，可适配任何 UI 库 | 解耦 | 深度绑定 antd |
| 类型支持 | 完善（TypeScript） | 一般 | 一般 |

**选型建议**：
- 如果在做低代码平台、需要复杂联动 → **Formily**
- 如果是普通后台管理系统 → **ProForm** 最快
- 如果项目用 antd 但需要一定程度的 Schema 化 → **FormRender**
