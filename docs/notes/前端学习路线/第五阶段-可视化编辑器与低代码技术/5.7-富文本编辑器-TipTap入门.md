# 富文本编辑器：TipTap 入门

## 富文本编辑器技术选型

在低代码平台中，富文本编辑器用于支持用户直接编辑段落、标题、列表等内容。主流方案：

| 方案 | 底层 | 特点 |
|:-----|:-----|:-----|
| **TipTap** | ProseMirror | 开箱即用，扩展体系完善，React/Vue 双支持，中文社区活跃 |
| Slate.js | 自研 | 灵活度最高，但学习曲线陡，API 变动频繁 |
| ProseMirror | 自研 | 底层框架，功能完备但需大量胶水代码 |
| Quill | 自研 | 简单易用，但架构限制多，扩展性差 |

推荐选择 **TipTap**：它在 ProseMirror 之上封装了易用的 React API，同时保留了完整的扩展能力。

## TipTap 核心概念

```
TipTap = ProseMirror 核心 + Extension 扩展体系 + React 集成
```

三个核心概念：
- **Extension（扩展）**：为编辑器添加行为，如加粗、斜体、历史记录
- **Node（节点）**：块级元素，如段落、标题、代码块、图片
- **Mark（标记）**：行内格式，如加粗、斜体、链接、行内代码

```tsx
import { useEditor, EditorContent } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';

function RichTextEditor() {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello World</p>',
  });

  return <EditorContent editor={editor} />;
}
```

## 基础编辑器搭建

完整示例：带工具栏的富文本编辑器。

```tsx
import { useEditor, EditorContent } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';

function BasicEditor({ content, onChange }) {
  const editor = useEditor({
    extensions: [StarterKit],
    content,
    onUpdate: ({ editor }) => {
      onChange?.(editor.getHTML());
    },
  });

  if (!editor) return null;

  return (
    <div className="editor-wrapper">
      {/* 工具栏 */}
      <div className="toolbar">
        <button
          onClick={() => editor.chain().focus().toggleBold().run()}
          className={editor.isActive('bold') ? 'active' : ''}
        >
          <strong>B</strong>
        </button>
        <button
          onClick={() => editor.chain().focus().toggleItalic().run()}
          className={editor.isActive('italic') ? 'active' : ''}
        >
          <em>I</em>
        </button>
        <button
          onClick={() => editor.chain().focus().toggleHeading({ level: 2 }).run()}
          className={editor.isActive('heading', { level: 2 }) ? 'active' : ''}
        >
          H2
        </button>
        <button
          onClick={() => editor.chain().focus().toggleBulletList().run()}
          className={editor.isActive('bulletList') ? 'active' : ''}
        >
          列表
        </button>
        <button
          onClick={() => editor.chain().focus().toggleCodeBlock().run()}
          className={editor.isActive('codeBlock') ? 'active' : ''}
        >
          代码块
        </button>
      </div>
      {/* 编辑区域 */}
      <EditorContent editor={editor} className="editor-content" />
    </div>
  );
}
```

工具栏按钮的 `editor.chain().focus().toggleXxx().run()` 是 TipTap 的命令链模式——可以链式调用多个编辑操作。

## 自定义节点与扩展

以"高亮提示块（Callout）"为例，创建一个自定义 TipTap 节点：

```tsx
import { Node, mergeAttributes } from '@tiptap/core';
import { ReactNodeViewRenderer } from '@tiptap/react';

// 1. 定义节点类型
const Callout = Node.create({
  name: 'callout',
  group: 'block',
  content: 'inline*',  // 接受行内内容

  addAttributes() {
    return {
      type: { default: 'info', parseHTML: el => el.dataset.type },
    };
  },

  parseHTML() {
    return [{ tag: 'div[data-callout]', attrs: { type: 'info' } }];
  },

  renderHTML({ HTMLAttributes }) {
    return ['div', mergeAttributes(HTMLAttributes, { 'data-callout': '' }), 0];
  },

  // React 组件渲染
  addNodeView() {
    return ReactNodeViewRenderer(CalloutComponent);
  },
});

// 2. 编写 React 视图组件
function CalloutComponent({ node, updateAttributes }) {
  const colors = { info: '#e6f7ff', warning: '#fffbe6', error: '#fff2f0' };

  return (
    <NodeViewWrapper>
      <div
        style={{ background: colors[node.attrs.type], padding: '8px 12px', borderRadius: 4, margin: '8px 0' }}
      >
        <select
          value={node.attrs.type}
          onChange={e => updateAttributes({ type: e.target.value })}
          style={{ marginBottom: 4 }}
        >
          <option value="info">信息</option>
          <option value="warning">警告</option>
          <option value="error">错误</option>
        </select>
        <NodeViewContent as="p" />
      </div>
    </NodeViewWrapper>
  );
}

// 3. 注册到编辑器
const editor = useEditor({
  extensions: [StarterKit, Callout],
  content: '<div data-callout data-type="warning">请注意这个配置！</div>',
});
```

## 富文本与 Schema 的集成

在低代码编辑器中，富文本节点作为 Schema 树的一部分存在。Schema 节点中存储 ProseMirror JSON 格式：

```json
{
  "id": "richtext-1",
  "componentName": "RichText",
  "props": {
    "content": {
      "type": "doc",
      "content": [
        {
          "type": "heading",
          "attrs": { "level": 2 },
          "content": [{ "type": "text", "text": "项目简介" }]
        },
        {
          "type": "paragraph",
          "content": [
            { "type": "text", "text": "这是一个" },
            { "type": "text", "marks": [{ "type": "bold" }], "text": "重要" },
            { "type": "text", "text": "的项目。" }
          ]
        }
      ]
    }
  }
}
```

RichText 组件在画布中渲染时，初始化一个只读 TipTap 编辑器；在属性面板中编辑时，切换为可编辑模式。

## 协作编辑简介

TipTap 可通过 **Yjs** 实现多人实时协作编辑：

```tsx
import * as Y from 'yjs';
import { WebsocketProvider } from 'y-websocket';
import { useCollaboration } from '@tiptap/extension-collaboration';

// Yjs 文档
const ydoc = new Y.Doc();
const provider = new WebsocketProvider('wss://your-server.com', 'doc-id', ydoc);

const editor = useEditor({
  extensions: [
    StarterKit.configure({ history: false }),  // 关闭本地历史，使用 Yjs 版本
    Collaboration.configure({ document: ydoc }),
  ],
});
```

协作编辑的关键概念：
- **Yjs CRDT**：冲突自动合并，无需锁机制
- **Awareness 协议**：显示其他用户的光标位置和选区
- **y-websocket**：Yjs 官方 WebSocket 同步后端
