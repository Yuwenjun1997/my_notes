# 表格解决方案：TanStack Table

TanStack Table v8 是"无头"（Headless）表格引擎——只管理状态和逻辑，不生成 DOM，让开发者完全掌控渲染方式，是企业级数据表格的最佳选择。

## 核心概念

| 需求 | TanStack Table 的解决方式 |
|:-----|:-------------------------|
| 排序 | 内置多列排序，支持自定义比较函数 |
| 筛选 | 内置列筛选 + 全局筛选 |
| 分页 | 内置前端分页，支持服务端分页 |
| 虚拟滚动 | 通过 @tanstack/react-virtual 集成 |

## useReactTable 基础

```tsx
import { useReactTable, getCoreRowModel, flexRender } from '@tanstack/react-table';
import type { ColumnDef } from '@tanstack/react-table';

interface User { id: number; name: string; email: string; role: string; }

const columns: ColumnDef<User>[] = [
  { accessorKey: 'id', header: 'ID' },
  { accessorKey: 'name', header: '姓名' },
  { accessorKey: 'email', header: '邮箱' },
  { accessorKey: 'role', header: '角色' },
];

function BasicTable({ data }: { data: User[] }) {
  const table = useReactTable({ data, columns, getCoreRowModel: getCoreRowModel() });
  return (
    <table>
      <thead>{table.getHeaderGroups().map(hg => (
        <tr key={hg.id}>{hg.headers.map(h => <th key={h.id}>{flexRender(h.column.columnDef.header, h.getContext())}</th>)}</tr>
      ))}</thead>
      <tbody>{table.getRowModel().rows.map(row => (
        <tr key={row.id}>{row.getVisibleCells().map(cell => <td key={cell.id}>{flexRender(cell.column.columnDef.cell, cell.getContext())}</td>)}</tr>
      ))}</tbody>
    </table>
  );
}
```

## 排序、筛选、分页

```tsx
import { useReactTable, getCoreRowModel, getSortedRowModel, getFilteredRowModel, getPaginationRowModel, flexRender } from '@tanstack/react-table';
import { useState } from 'react';

function ProductTable({ data }: { data: Product[] }) {
  const [sorting, setSorting] = useState([]);
  const [globalFilter, setGlobalFilter] = useState('');
  const [pagination, setPagination] = useState({ pageIndex: 0, pageSize: 10 });

  const table = useReactTable({
    data, columns,
    state: { sorting, globalFilter, pagination },
    onSortingChange: setSorting, onGlobalFilterChange: setGlobalFilter, onPaginationChange: setPagination,
    getCoreRowModel: getCoreRowModel(), getSortedRowModel: getSortedRowModel(),
    getFilteredRowModel: getFilteredRowModel(), getPaginationRowModel: getPaginationRowModel(),
  });

  return (
    <div>
      <input value={globalFilter} onChange={e => setGlobalFilter(e.target.value)} placeholder="搜索..." />
      <table>
        <thead>{table.getHeaderGroups().map(hg => (
          <tr key={hg.id}>{hg.headers.map(h => (
            <th key={h.id} onClick={h.column.getToggleSortingHandler()} style={{ cursor: 'pointer' }}>
              {flexRender(h.column.columnDef.header, h.getContext())}
              {{ asc: ' ↑', desc: ' ↓' }[h.column.getIsSorted() as string] ?? ''}
            </th>
          ))}</tr>
        ))}</thead>
        <tbody>{table.getRowModel().rows.map(row => (
          <tr key={row.id}>{row.getVisibleCells().map(cell => <td key={cell.id}>{flexRender(cell.column.columnDef.cell, cell.getContext())}</td>)}</tr>
        ))}</tbody>
      </table>
      <div>
        <button onClick={() => table.previousPage()} disabled={!table.getCanPreviousPage()}>上一页</button>
        <span> {pagination.pageIndex + 1} / {table.getPageCount()} </span>
        <button onClick={() => table.nextPage()} disabled={!table.getCanNextPage()}>下一页</button>
      </div>
    </div>
  );
}
```

## 无头模式优势

传统表格组件库内置样式和 DOM，定制需覆写大量 CSS。TanStack Table 不生成 DOM，同一逻辑可渲染为 HTML table、卡片网格或移动端列表，只需改变渲染层。

## 实战：企业级数据表格

```tsx
// EnterpriseTable 组件 - 企业级数据表格示例
// 包含排序、筛选、分页和虚拟滚动
function EnterpriseTable({ data }: { data: Employee[] }) {
  const [sorting, setSorting] = useState([]);
  const [globalFilter, setGlobalFilter] = useState('');
  const [pagination, setPagination] = useState({ pageIndex: 0, pageSize: 50 });
  const containerRef = useRef(null);

  const columns = useMemo(() => [
    { accessorKey: 'id', header: '工号', size: 80 },
    { accessorKey: 'name', header: '姓名', size: 120 },
    { accessorKey: 'department', header: '部门', size: 150 },
    { accessorKey: 'salary', header: '薪资', cell: info => `¥${info.getValue().toLocaleString()}` },
    { accessorKey: 'joinDate', header: '入职日期' },
  ], []);

  const table = useReactTable({
    data, columns,
    state: { sorting, globalFilter, pagination },
    onSortingChange: setSorting, onGlobalFilterChange: setGlobalFilter,
    onPaginationChange: setPagination,
    getCoreRowModel: getCoreRowModel(),
    getSortedRowModel: getSortedRowModel(),
    getFilteredRowModel: getFilteredRowModel(),
    getPaginationRowModel: getPaginationRowModel(),
  });

  return table;
}
```

## 要点总结

- TanStack Table 是 Headless 表格引擎，只管理状态和逻辑，渲染完全由开发者控制
- `useReactTable` 接收 `columns` + `data` + 行模型，返回表格实例
- 列定义支持 `cell` 渲染函数、`sortingFn` 自定义排序、`size` 控制列宽
- 虚拟滚动通过 `@tanstack/react-virtual` 集成，适合万级以上数据
- 列定义用 `useMemo` 缓存避免不必要的重计算
