# React 测试 - React Testing Library

测试是保证代码质量的重要手段，React Testing Library (RTL) 以其"测试用户行为而非实现细节"的设计哲学，成为了 React 测试的事实标准。本篇将全面介绍 RTL 的使用方法，从基础到进阶，帮助你构建可靠的测试体系。

## 测试金字塔与 RTL 设计哲学

### 测试金字塔

| 层级 | 类型 | 数量 | 速度 | 成本 | 维护性 |
|------|------|------|------|------|--------|
| 顶层 | E2E 测试 | 少 | 慢 | 高 | 低 |
| 中层 | 集成测试 | 中 | 中 | 中 | 中 |
| 底层 | 单元测试 | 多 | 快 | 低 | 高 |

### RTL 设计哲学

RTL 的核心原则：**"The more your tests resemble the way your software is used, the more confidence they can give you."**

```jsx
// ❌ 实现细节测试（不推荐）
test('calls onChange when input changes', () => {
  const onChange = jest.fn();
  render(<Input onChange={onChange} />);
  const input = screen.getByTestId('custom-input');  // 依赖测试 ID
  fireEvent.change(input, { target: { value: 'test' } });
  expect(onChange).toHaveBeenCalledWith('test');
});

// ✅ 行为测试（推荐）
test('allows user to enter text', async () => {
  const user = userEvent.setup();
  render(<LoginForm />);
  const input = screen.getByLabelText(/username/i);  // 使用可访问名称
  await user.type(input, 'testuser');
  expect(input).toHaveValue('testuser');
});
```

## 基础用法

### render 与 screen

```tsx
import { render, screen } from '@testing-library/react';
import { Greeting } from './Greeting';

describe('Greeting', () => {
  test('renders welcome message', () => {
    render(<Greeting name="Alice" />);
    expect(screen.getByText('Hello, Alice!')).toBeInTheDocument();
  });

  test('renders with default name', () => {
    render(<Greeting />);
    expect(screen.getByText('Hello, World!')).toBeInTheDocument();
  });

  test('renders optional message', () => {
    render(<Greeting name="Bob" message="Welcome back" />);
    expect(screen.getByText('Welcome back')).toBeInTheDocument();
  });
});
```

### 查询元素的方法

| 方法 | 返回 | 断言失败时 | 适用场景 |
|------|------|-----------|---------|
| `getBy*` | 单个元素 | 报错 | 必须存在的元素 |
| `queryBy*` | 单个或 null | 断言失败 | 可能不存在的元素 |
| `findBy*` | Promise | 超时报错 | 异步渲染的元素 |

```tsx
// getBy - 查找必须存在的元素
const button = screen.getByRole('button', { name: 'Submit' });
const input = screen.getByLabelText('Email');
const text = screen.getByText('Success');

// queryBy - 查找可能不存在的元素
const error = screen.queryByText('Error message');
expect(error).not.toBeInTheDocument();  // 验证不存在

// findBy - 异步查找元素（等待出现）
const loading = await screen.findByText('Loading...');
const modal = await screen.findByRole('dialog');
```

### 查询优先级

RTL 推荐按以下优先级选择查询方法：

1. **getByRole** - 最符合可访问性实践
2. **getByLabelText** - 表单元素首选
3. **getByPlaceholderText** - 次选表单查询
4. **getByText** - 非交互元素
5. **getByDisplayValue** - 已填充的表单元素
6. **getByAltText** - 图片
7. **getByTitle** - 标题属性
8. **getByTestId** - 最后手段

```tsx
// 推荐的查询方式
screen.getByRole('button', { name: /submit/i });
screen.getByLabelText('Email address');
screen.getByPlaceholderText('Enter your password');
screen.getByText('Welcome to our app');
screen.getByAltText('Company logo');

// 避免使用
screen.getByTestId('submit-button');  // 最后手段
```

## 用户交互

### fireEvent vs userEvent

```tsx
import { render, screen, fireEvent } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { Counter } from './Counter';

describe('Counter', () => {
  test('increments with fireEvent', () => {
    render(<Counter />);
    const button = screen.getByRole('button', { name: /increment/i });

    fireEvent.click(button);
    fireEvent.click(button);

    expect(screen.getByText('Count: 2')).toBeInTheDocument();
  });

  test('increments with userEvent', async () => {
    const user = userEvent.setup();
    render(<Counter />);
    const button = screen.getByRole('button', { name: /increment/i });

    await user.click(button);
    await user.click(button);

    expect(screen.getByText('Count: 2')).toBeInTheDocument();
  });

  test('handles complex user interactions', async () => {
    const user = userEvent.setup();
    render(<SignUpForm />);

    const nameInput = screen.getByLabelText(/name/i);
    const emailInput = screen.getByLabelText(/email/i);
    const submitButton = screen.getByRole('button', { name: /sign up/i });

    await user.type(nameInput, 'John Doe');
    await user.type(emailInput, 'john@example.com');
    await user.click(submitButton);

    expect(screen.getByText('Success!')).toBeInTheDocument();
  });
});
```

| 特性 | fireEvent | userEvent |
|------|-----------|-----------|
| 真实性 | 低 | 高 |
| 触发完整事件链 | 否 | 是 |
| 异步支持 | 否 | 是 |
| 推荐度 | ⭐⭐ | ⭐⭐⭐⭐⭐ |

## 异步测试

### waitFor 与 findBy

```tsx
import { render, screen, waitFor } from '@testing-library/react';
import { UserProfile } from './UserProfile';

describe('UserProfile', () => {
  // 使用 waitFor
  test('loads and displays user data', async () => {
    render(<UserProfile userId={1} />);

    await waitFor(() => {
      expect(screen.getByText('John Doe')).toBeInTheDocument();
    });

    expect(screen.getByText('john@example.com')).toBeInTheDocument();
  });

  // 使用 findBy（更简洁）
  test('loads and displays user data', async () => {
    render(<UserProfile userId={1} />);

    const name = await screen.findByText('John Doe');
    expect(name).toBeInTheDocument();

    const email = await screen.findByText('john@example.com');
    expect(email).toBeInTheDocument();
  });

  // 处理加载状态
  test('shows loading state then data', async () => {
    render(<UserProfile userId={1} />);

    expect(screen.getByText('Loading...')).toBeInTheDocument();

    await screen.findByText('John Doe');

    expect(screen.queryByText('Loading...')).not.toBeInTheDocument();
  });

  // 自定义超时时间
  test('slow API call', async () => {
    render(<SlowComponent />);

    const data = await screen.findByText('Data loaded', {}, { timeout: 5000 });
    expect(data).toBeInTheDocument();
  });
});
```

### 处理 Promise 和异步操作

```tsx
// 测试异步操作
describe('AsyncComponent', () => {
  test('handles successful fetch', async () => {
    const mockData = { name: 'Test User' };
    global.fetch = jest.fn().mockResolvedValue({
      ok: true,
      json: () => Promise.resolve(mockData),
    });

    render(<AsyncComponent />);

    expect(screen.getByText('Loading...')).toBeInTheDocument();

    const name = await screen.findByText('Test User');
    expect(name).toBeInTheDocument();
  });

  test('handles fetch error', async () => {
    global.fetch = jest.fn().mockRejectedValue(new Error('Network error'));

    render(<AsyncComponent />);

    const error = await screen.findByText(/error/i);
    expect(error).toBeInTheDocument();
  });
});
```

## Mock 技术

### Mock API 请求 (MSW)

```tsx
// src/mocks/handlers.js
import { http, HttpResponse } from 'msw';

export const handlers = [
  http.get('/api/users', () => {
    return HttpResponse.json([
      { id: 1, name: 'John' },
      { id: 2, name: 'Jane' },
    ]);
  }),

  http.post('/api/login', async ({ request }) => {
    const { email, password } = await request.json();

    if (email === 'test@example.com' && password === 'password') {
      return HttpResponse.json({ token: 'fake-token' });
    }

    return new HttpResponse(null, { status: 401 });
  }),
];

// src/mocks/server.js
import { setupServer } from 'msw/node';
import { handlers } from './handlers';

export const server = setupServer(...handlers);

// src/setupTests.js
import { server } from './mocks/server';

beforeAll(() => server.listen());
afterEach(() => server.resetHandlers());
afterAll(() => server.close());

// 测试文件
import { render, screen, waitFor } from '@testing-library/react';
import { UserList } from './UserList';
import { rest } from 'msw';
import { server } from '../mocks/server';

describe('UserList', () => {
  test('renders users from API', async () => {
    render(<UserList />);

    const users = await screen.findAllByRole('listitem');
    expect(users).toHaveLength(2);
  });

  test('handles API error', async () => {
    server.use(
      rest.get('/api/users', (req, res, ctx) => {
        return res(ctx.status(500));
      })
    );

    render(<UserList />);

    const error = await screen.findByText(/error/i);
    expect(error).toBeInTheDocument();
  });
});
```

## 实战：测试完整的登录组件

```tsx
// LoginForm.tsx
import React, { useState } from 'react';

interface LoginFormProps {
  onSubmit: (email: string, password: string) => Promise<void>;
  error?: string;
}

export function LoginForm({ onSubmit, error }: LoginFormProps) {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [loading, setLoading] = useState(false);

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setLoading(true);
    try {
      await onSubmit(email, password);
    } finally {
      setLoading(false);
    }
  };

  return (
    <form onSubmit={handleSubmit} aria-label="login form">
      <div>
        <label htmlFor="email">Email</label>
        <input
          id="email"
          type="email"
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          required
          aria-describedby={error ? 'login-error' : undefined}
        />
      </div>

      <div>
        <label htmlFor="password">Password</label>
        <input
          id="password"
          type="password"
          value={password}
          onChange={(e) => setPassword(e.target.value)}
          required
        />
      </div>

      {error && (
        <div id="login-error" role="alert">
          {error}
        </div>
      )}

      <button type="submit" disabled={loading}>
        {loading ? 'Logging in...' : 'Login'}
      </button>
    </form>
  );
}

// LoginForm.test.tsx
import React from 'react';
import { render, screen, waitFor } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { LoginForm } from './LoginForm';

describe('LoginForm', () => {
  const mockOnSubmit = jest.fn();

  beforeEach(() => {
    mockOnSubmit.mockClear();
  });

  test('renders login form', () => {
    render(<LoginForm onSubmit={mockOnSubmit} />);

    expect(screen.getByLabelText(/email/i)).toBeInTheDocument();
    expect(screen.getByLabelText(/password/i)).toBeInTheDocument();
    expect(screen.getByRole('button', { name: /login/i })).toBeInTheDocument();
  });

  test('allows user to type in fields', async () => {
    const user = userEvent.setup();
    render(<LoginForm onSubmit={mockOnSubmit} />);

    const emailInput = screen.getByLabelText(/email/i);
    const passwordInput = screen.getByLabelText(/password/i);

    await user.type(emailInput, 'test@example.com');
    await user.type(passwordInput, 'password123');

    expect(emailInput).toHaveValue('test@example.com');
    expect(passwordInput).toHaveValue('password123');
  });

  test('calls onSubmit with credentials', async () => {
    const user = userEvent.setup();
    mockOnSubmit.mockResolvedValue(undefined);

    render(<LoginForm onSubmit={mockOnSubmit} />);

    await user.type(screen.getByLabelText(/email/i), 'test@example.com');
    await user.type(screen.getByLabelText(/password/i), 'password123');
    await user.click(screen.getByRole('button', { name: /login/i }));

    expect(mockOnSubmit).toHaveBeenCalledWith(
      'test@example.com',
      'password123'
    );
  });

  test('shows loading state during submission', async () => {
    const user = userEvent.setup();
    let resolveSubmit: () => void;
    mockOnSubmit.mockImplementation(
      () => new Promise<void>((resolve) => { resolveSubmit = resolve; })
    );

    render(<LoginForm onSubmit={mockOnSubmit} />);

    await user.type(screen.getByLabelText(/email/i), 'test@example.com');
    await user.type(screen.getByLabelText(/password/i), 'password123');
    await user.click(screen.getByRole('button', { name: /login/i }));

    expect(screen.getByRole('button', { name: /logging in/i })).toBeDisabled();

    resolveSubmit!();
    await waitFor(() => {
      expect(screen.getByRole('button', { name: /login/i })).toBeEnabled();
    });
  });

  test('displays error message', () => {
    render(<LoginForm onSubmit={mockOnSubmit} error="Invalid credentials" />);

    expect(screen.getByRole('alert')).toHaveTextContent('Invalid credentials');
  });

  test('validates required fields', async () => {
    const user = userEvent.setup();
    render(<LoginForm onSubmit={mockOnSubmit} />);

    await user.click(screen.getByRole('button', { name: /login/i }));

    expect(mockOnSubmit).not.toHaveBeenCalled();
    expect(screen.getByLabelText(/email/i)).toBeInvalid();
    expect(screen.getByLabelText(/password/i)).toBeInvalid();
  });
});
```

## 最佳实践

1. **测试用户行为，不测试实现** - 关注组件的输出和交互
2. **使用可访问性查询** - 优先使用 `getByRole`、`getByLabelText`
3. **使用 userEvent 替代 fireEvent** - 更真实的用户交互模拟
4. **测试异步操作** - 使用 `waitFor` 或 `findBy*`
5. **Mock 外部依赖** - API 请求、浏览器 API 等
6. **保持测试独立** - 每个测试应该可以独立运行
7. **使用 describe 组织测试** - 按功能模块组织测试用例
8. **编写清晰的断言** - 使用 `toBeInTheDocument`、`toHaveValue` 等语义化断言
9. **避免测试快照** - 快照测试容易失效且难以维护
10. **持续集成中运行测试** - 确保每次提交都经过测试

通过遵循这些实践，你将能够构建出可靠、可维护的 React 测试套件。
