# TypeScript与React深度集成

TypeScript 已成为 React 项目的标配，它不仅能捕获类型错误，还能大幅改善开发体验和代码可维护性。本篇将深入探讨 TypeScript 与 React 的集成技巧，涵盖从基础类型定义到高级泛型组件的完整知识体系。

## 函数组件类型定义

### 是否使用 FC？这是一个问题

React 早期版本推荐使用 `React.FC`，但在 React 18+ 中，官方不再推荐在函数组件中使用 `FC`。

| 方式 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| `React.FC<Props>` | 自动包含 children 类型 | 过于宽泛，隐藏了隐式 props | ⭐⭐ |
| 直接函数签名 | 类型推导更精确，更灵活 | 需要手动声明返回类型 | ⭐⭐⭐⭐⭐ |
| `React.ComponentType` | 适合高阶组件 | 语法相对复杂 | ⭐⭐⭐ |

```tsx
// 方式一：使用 FC（不推荐）
const Button1: React.FC<{ label: string; onClick: () => void }> = ({ label, onClick }) => {
  return <button onClick={onClick}>{label}</button>;
};

// 方式二：直接函数签名（推荐）
interface ButtonProps {
  label: string;
  onClick: () => void;
  variant?: 'primary' | 'secondary';
}

function Button({ label, onClick, variant = 'primary' }: ButtonProps) {
  return (
    <button
      className={`btn btn-${variant}`}
      onClick={onClick}
    >
      {label}
    </button>
  );
}

// 方式三：箭头函数 + 类型注解
const IconButton = ({ icon, label, onClick }: ButtonProps & { icon: React.ReactNode }) => {
  return (
    <button onClick={onClick}>
      {icon} {label}
    </button>
  );
};
```

```tsx
// 泛型下拉框组件
interface SelectProps<T extends string | number> {
  options: { value: T; label: string }[];
  value?: T;
  onChange: (value: T) => void;
  placeholder?: string;
}

function Select<T extends string | number>({
  options,
  value,
  onChange,
  placeholder = '请选择',
}: SelectProps<T>) {
  return (
    <select
      value={value}
      onChange={(e) => onChange(e.target.value as T)}
    >
      <option value="">{placeholder}</option>
      {options.map((option) => (
        <option key={option.value} value={option.value}>
          {option.label}
        </option>
      ))}
    </select>
  );
}
```

### 自定义 Hook 类型

```tsx
// 完整的自定义 Hook 类型示例
interface UseFetchResult<T> {
  data: T | null;
  loading: boolean;
  error: Error | null;
  refetch: () => void;
}

function useFetch<T>(url: string): UseFetchResult<T> {
  const [data, setData] = useState<T | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  const fetchData = useCallback(async () => {
    try {
      setLoading(true);
      const response = await fetch(url);
      if (!response.ok) {
        throw new Error(`HTTP error! status: ${response.status}`);
      }
      const result = await response.json();
      setData(result);
      setError(null);
    } catch (err) {
      setError(err instanceof Error ? err : new Error('Unknown error'));
    } finally {
      setLoading(false);
    }
  }, [url]);

  useEffect(() => {
    fetchData();
  }, [fetchData]);

  return { data, loading, error, refetch: fetchData };
}

// 使用示例
interface Todo {
  id: number;
  title: string;
  completed: boolean;
}

function TodoList() {
  const { data: todos, loading, error } = useFetch<Todo[]>(
    'https://jsonplaceholder.typicode.com/todos?_limit=10'
  );

  if (loading) return <div>加载中...</div>;
  if (error) return <div>错误：{error.message}</div>;

  return (
    <ul>
      {todos?.map((todo) => (
        <li key={todo.id} className={todo.completed ? 'completed' : ''}>
          {todo.title}
        </li>
      ))}
    </ul>
  );
}
```

```tsx
// 问题：事件处理函数类型错误
// 错误示例

function SearchForm() {
  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {

    const formData = new FormData(e.currentTarget);

      <input
```

### 表单元素类型

```tsx
// 处理动态表单
interface DynamicFormProps {
  fields: Array<{
    name: string;
    type: 'text' | 'number' | 'email' | 'select';
    label: string;
    options?: Array<{ value: string; label: string }>;
  }>;
  values: Record<string, string>;
  onChange: (name: string, value: string) => void;
}

function DynamicForm({ fields, values, onChange }: DynamicFormProps) {
  const handleFieldChange = (
    name: string,
    type: string
  ): React.ChangeEventHandler<HTMLInputElement | HTMLSelectElement> => {
    return (e) => {
      let value = e.target.value;
      if (type === 'number') {
        value = value.replace(/[^0-9]/g, '');
      }
      onChange(name, value);
    };
  };

  return (
    <div className="dynamic-form">
      {fields.map((field) => (
        <div key={field.name} className="form-field">
          <label>{field.label}</label>
          {field.type === 'select' ? (
            <select
              value={values[field.name] || ''}
              onChange={handleFieldChange(field.name, field.type)}
            >
              <option value="">请选择</option>
              {field.options?.map((option) => (
                <option key={option.value} value={option.value}>
                  {option.label}
                </option>
              ))}
            </select>
          ) : (
            <input
              type={field.type}
              value={values[field.name] || ''}
              onChange={handleFieldChange(field.name, field.type)}
            />
          )}
        </div>
      ))}
    </div>
  );
}
```

## 实战：类型安全的泛型 Button 组件

```tsx
import React from 'react';

// 按钮变体类型
type ButtonVariant = 'primary' | 'secondary' | 'danger' | 'ghost';
type ButtonSize = 'small' | 'medium' | 'large';

// 基础按钮 Props
interface BaseButtonProps {
  children: React.ReactNode;
  variant?: ButtonVariant;
  size?: ButtonSize;
  disabled?: boolean;
  loading?: boolean;
  fullWidth?: boolean;
}

// 链接按钮 Props
interface LinkButtonProps extends BaseButtonProps {
  as: 'link';
  href: string;
  target?: '_blank' | '_self';
}

// 提交按钮 Props
interface SubmitButtonProps extends BaseButtonProps {
  as?: 'button';
  type?: 'submit';
}

// 普通按钮 Props
interface RegularButtonProps extends BaseButtonProps {
  as?: 'button';
  type?: 'button' | 'reset';
  onClick?: React.MouseEventHandler<HTMLButtonElement>;
}

// 联合类型
type ButtonProps = LinkButtonProps | SubmitButtonProps | RegularButtonProps;

// 样式映射
const variantStyles: Record<ButtonVariant, string> = {
  primary: 'bg-blue-500 text-white hover:bg-blue-600',
  secondary: 'bg-gray-200 text-gray-800 hover:bg-gray-300',
  danger: 'bg-red-500 text-white hover:bg-red-600',
  ghost: 'bg-transparent text-gray-600 hover:bg-gray-100',
};

const sizeStyles: Record<ButtonSize, string> = {
  small: 'px-3 py-1 text-sm',
  medium: 'px-4 py-2 text-base',
  large: 'px-6 py-3 text-lg',
};

// 泛型按钮组件
function Button<T extends 'link' | 'button' = 'button'>(
  props: T extends 'link' ? LinkButtonProps : RegularButtonProps | SubmitButtonProps
) {
  const {
    children,
    variant = 'primary',
    size = 'medium',
    disabled = false,
    loading = false,
    fullWidth = false,
    ...rest
  } = props;

  const baseClasses = 'inline-flex items-center justify-center font-medium rounded-md transition-colors focus:outline-none focus:ring-2 focus:ring-offset-2 disabled:opacity-50 disabled:cursor-not-allowed';

  const classes = `
    ${baseClasses}
    ${variantStyles[variant]}
    ${sizeStyles[size]}
    ${fullWidth ? 'w-full' : ''}
  `.trim();

  // Loading 状态内容
  const content = loading ? (
    <>
      <svg
        className="animate-spin -ml-1 mr-2 h-4 w-4"
        xmlns="http://www.w3.org/2000/svg"
        fill="none"
        viewBox="0 0 24 24"
      >
        <circle
          className="opacity-25"
          cx="12"
          cy="12"
          r="10"
          stroke="currentColor"
          strokeWidth="4"
        />
        <path
          className="opacity-75"
          fill="currentColor"
          d="M4 12a8 8 0 018-8V0C5.373 0 0 5.373 0 12h4zm2 5.291A7.962 7.962 0 014 12H0c0 3.042 1.135 5.824 3 7.938l3-2.647z"
        />
      </svg>
      处理中...
    </>
  ) : children;

  // 根据 as 属性渲染不同元素
  if (rest.as === 'link') {
    const { href, target, ...linkRest } = rest;
    return (
      <a
        href={href}
        target={target}
        className={classes}
        {...linkRest}
      >
        {content}
      </a>
    );
  }

  const { type = 'button', onClick, ...buttonRest } = rest;
  return (
    <button
      type={type}
      onClick={onClick}
      disabled={disabled || loading}
      className={classes}
      {...buttonRest}
    >
      {content}
    </button>
  );
}

// 使用示例
function App() {
  return (
    <div className="space-y-4">
      {/* 普通按钮 */}
      <Button onClick={() => console.log('clicked')}>
        点击我
      </Button>

      {/* 变体按钮 */}
      <Button variant="danger" size="large">
        删除
      </Button>

      {/* 加载状态 */}
      <Button loading disabled>
        提交中
      </Button>

      {/* 链接按钮 */}
      <Button as="link" href="/about" target="_blank">
        了解更多
      </Button>

      {/* 全宽按钮 */}
      <Button fullWidth variant="secondary">
        全宽按钮
      </Button>
    </div>
  );
}

export default App;
```

## 最佳实践总结

1. **优先使用函数签名而非 FC** - 更精确的类型推导
2. **为 Props 定义专门的接口** - 提高代码可读性和复用性
3. **使用泛型创建可复用组件** - 保持类型安全的同时提高灵活性
4. **合理使用类型断言** - 只在必要时使用 `as` 关键字
5. **利用工具类型** - `Partial`、`Pick`、`Omit` 简化类型定义
6. **为自定义 Hook 定义返回类型** - 提供清晰的 API 契约
7. **处理事件类型** - 使用 React 内置的事件类型定义
8. **避免 any** - 使用 `unknown` 替代，需要时再进行类型收窄

掌握这些 TypeScript 与 React 集成技巧，将显著提升你的 React 开发效率和代码质量。
