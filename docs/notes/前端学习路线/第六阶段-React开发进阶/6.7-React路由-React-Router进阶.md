# React 路由进阶

React Router v6 引入嵌套路由、布局路由等现代模式。本篇深入讲解嵌套路由、路由守卫、懒加载等进阶用法，并介绍类型安全的 TanStack Router。

## Routes 与嵌套路由

v6 使用 `Routes` + `Route`，嵌套路由通过 `Outlet` 声明子路由渲染位置：

```jsx
import { BrowserRouter, Routes, Route, Outlet, NavLink } from 'react-router-dom';

function Layout() {
  return (
    <div>
      <nav><NavLink to="/dashboard">仪表盘</NavLink><NavLink to="/dashboard/settings">设置</NavLink></nav>
      <main><Outlet /></main>
    </div>
  );
}

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />
          <Route path="dashboard" element={<Dashboard />}>
            <Route index element={<DashboardHome />} />
            <Route path="settings" element={<Settings />} />
            <Route path="profile" element={<Profile />} />
          </Route>
        </Route>
      </Routes>
    </BrowserRouter>
  );
}
```

| API | 用途 | 特点 |
|:----|:-----|:-----|
| `Routes` | 路由匹配容器 | 选择最佳匹配 |
| `Outlet` | 子路由占位符 | 嵌套路由的关键 |
| `NavLink` | 带激活状态的链接 | 自动添加 `active` class |
| `Navigate` | 声明式重定向 | 替代 v5 的 `Redirect` |

## 路由守卫

v6 通过 `ProtectedRoute` 组件模式实现权限控制：

```jsx
import { Navigate, useLocation } from 'react-router-dom';

function ProtectedRoute({ children, requiredRole }) {
  const { user, isAuthenticated } = useAuth();
  const location = useLocation();
  if (!isAuthenticated) return <Navigate to="/login" state={{ from: location }} replace />;
  if (requiredRole && user.role !== requiredRole) return <Navigate to="/unauthorized" replace />;
  return children;
}

// 使用方式
<Route path="admin" element={<ProtectedRoute requiredRole="admin"><AdminPanel /></ProtectedRoute>} />
```

## 路由懒加载

```jsx
import { lazy, Suspense } from 'react';
const Dashboard = lazy(() => import('./pages/Dashboard'));
const Settings  = lazy(() => import('./pages/Settings'));

function App() {
  return (
    <Suspense fallback={<div>加载中...</div>}>
      <Routes>
        <Route path="/dashboard" element={<Dashboard />}>
          <Route path="settings" element={<Settings />} />
        </Route>
      </Routes>
    </Suspense>
  );
}
```

嵌套路由中，只需在外层 `Suspense` 包裹一次即可。

## 高级 Hook 用法

### useSearchParams

将筛选条件持久化到 URL，支持浏览器前进后退：

```jsx
import { useSearchParams } from 'react-router-dom';

function ProductList() {
  const [searchParams, setSearchParams] = useSearchParams();
  const category = searchParams.get('category') || 'all';
  return (
    <select value={category} onChange={e => setSearchParams(p => { p.set('category', e.target.value); return p; })}>
      <option value="all">全部</option>
      <option value="electronics">电子产品</option>
    </select>
  );
}
```

### useParams 与 useLocation

```jsx
import { useParams, useLocation, useNavigate } from 'react-router-dom';

function ArticlePage() {
  const { id } = useParams();
  const location = useLocation();
  const navigate = useNavigate();
  const tab = new URLSearchParams(location.search).get('tab') || 'content';
  return <article><h1>文章 #{id}</h1><p>Tab: {tab}</p><button onClick={() => navigate(-1)}>返回</button></article>;
}
```

## TanStack Router 入门

TanStack Router 是类型安全路由库，解决了 React Router 在 TypeScript 类型推断上的不足：

```tsx
import { createRouter, createRoute, createRootRoute } from '@tanstack/react-router';

const rootRoute = createRootRoute({ component: () => <Outlet /> });

const userDetailRoute = createRoute({
  getParentRoute: () => rootRoute,
  path: '/users/$id',    // $id 自动推断为 string
  component: UserDetail,
});

const router = createRouter({ routeTree: rootRoute.addChildren([userDetailRoute]) });

function UserDetail() {
  const { id } = userDetailRoute.useParams();  // 类型安全
  return <div>用户 ID: {id}</div>;
}
```

搜索参数支持 Zod 校验，通过 `validateSearch` 在路由定义时自动校验：

```tsx
const usersRoute = createRoute({
  getParentRoute: () => rootRoute, path: '/users',
  validateSearch: (search) => z.object({ page: z.number().default(1) }).parse(search),
  component: UserList,
});
```

## 实战：多层级路由 + 权限 + 懒加载

```jsx
import { lazy, Suspense } from 'react';
const Login = lazy(() => import('./pages/Login'));
const Home  = lazy(() => import('./pages/Home'));
const Users = lazy(() => import('./pages/Users'));

function App() {
  return (
    <BrowserRouter>
      <Suspense fallback={<div>加载中...</div>}>
        <Routes>
          <Route path="/login" element={<Login />} />
          <Route path="/" element={<ProtectedRoute><SidebarLayout /></ProtectedRoute>}>
            <Route index element={<Home />} />
            <Route path="users" element={<Users />} />
          </Route>
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}
```

## 要点总结

- `Routes` 选择最佳匹配，嵌套路由通过 `Outlet` 实现
- 路由守卫通过 `ProtectedRoute` 组件模式实现
- 懒加载使用 `React.lazy()` + `Suspense`，外层包裹一次即可
- `useSearchParams` 将筛选条件持久化到 URL
- TanStack Router 提供完整 TypeScript 类型推断，搜索参数可用 Zod 校验
