# 原型、this 与继承

JS 的对象通过「原型链」实现复用与继承，`this` 的绑定规则与其它语言差别很大。掌握这两块，很多面试高频题与源码困惑都会迎刃而解。

## 原型与原型链

每个对象都有隐藏的 `[[Prototype]]`，指向另一个对象（其原型）。访问属性时，先找自身，找不到就沿着 `__proto__` 逐层向上找：

```js
const parent = { name: 'parent' };
const child = Object.create(parent);  // child 的原型是 parent
child.age = 3;

console.log(child.name);      // 'parent'：自身没有，沿原型链找到
console.log(child.hasOwnProperty('name')); // false，是原型上的属性
```

链的终点是 `Object.prototype`，再往上为 `null`。数组、函数等内置对象的原型链更复杂，例如数组 `[]` 的原型是 `Array.prototype`，其上定义了 `push/map` 等方法。

## constructor 与 new

```js
function Person(name) {
  this.name = name;
}
Person.prototype.say = function () {
  return `Hi, I am ${this.name}`;
};
```

`new Person('Tom')` 的四个步骤：

1. 创建一个新对象。
2. 新对象的原型指向 `Person.prototype`。
3. 以新对象为 `this` 执行构造函数。
4. 若构造函数返回对象则用之，否则返回新对象。

`instanceof` 沿原型链判断：`tom instanceof Person` 为 true。

## this 的四种绑定

`this` 在**调用时**决定（箭头函数除外），不是定义时：

| 场景 | 调用方式 | this 指向 |
|:-----|:---------|:----------|
| 默认绑定 | `fn()` 直接调用 | 非严格模式 globalThis / 严格模式 undefined |
| 隐式绑定 | `obj.method()` | 点号前的对象（obj） |
| 显式绑定 | `call/apply/bind` | 显式传入的对象 |
| 新绑定 | `new Fn()` | 新创建的对象 |

```js
const user = {
  name: 'Tom',
  hello() { return `Hi ${this.name}`; },
};
user.hello();                       // 隐式：this = user
const fn = user.hello;
fn();                               // 丢失绑定：this 不是 user
fn.call(user);                      // 显式：this = user
const bound = fn.bind(user);        // 永久绑定
bound();                            // this = user
```

**箭头函数**：没有自己的 this，沿外层词法作用域取 this，也不能被 call/bind 改变。常用于回调、事件处理里保留外层 this。

```js
const timer = {
  count: 0,
  start() {
    setInterval(() => {
      this.count++;     // 箭头函数：this 是 start 外层的 timer
    }, 1000);
  },
};
```

## class 语法糖

ES6 的 `class` 本质是原型机制的语法糖，底层仍是构造函数 + prototype：

```js
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {               // 挂在 Animal.prototype 上
    return `${this.name} speaks`;
  }
}

class Dog extends Animal {
  constructor(name) {
    super(name);          // 调用父类构造函数，先于 this 使用
    this.species = 'dog';
  }
  speak() {               // 覆盖父类方法
    return `${super.speak()} woof!`;   // super 调用父类方法
  }
}
```

- `extends` 建立继承关系：`Dog.prototype` 的原型是 `Animal.prototype`。
- `static` 静态成员挂在类本身：`Animal.create()`。
- 私有字段：`#secret`，真正的外部不可访问。

## 组合与继承的选择

继承适合清晰的「is-a」关系；多数场景用**组合**（对象包含对象、mixin 混入）更灵活。JS 中「组合优于继承」是常态，不必强行造一层类层级。
