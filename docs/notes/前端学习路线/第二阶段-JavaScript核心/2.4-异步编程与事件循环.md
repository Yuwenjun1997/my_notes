# 异步编程与事件循环

JS 在浏览器中是**单线程**的：同一时间只能执行一段代码。异步编程让耗时操作（网络请求、定时器、文件读取）不阻塞页面，配合事件循环（Event Loop）调度执行顺序。

## 为什么需要异步

```js
// 同步代码会阻塞：下面的 setTimeout 之前的阻塞操作会让页面卡死
console.log(1);
setTimeout(() => console.log(2), 0);
console.log(3);
// 输出：1 3 2
```

`setTimeout(..., 0)` 只是「尽快排在任务队列后面」，不是立即执行。输出顺序取决于事件循环的调度。

## 回调函数与回调地狱

回调是最原始的异步写法：

```js
fetchData(id, (data) => {
  save(data, () => {
    notify(() => {
      // 嵌套一层套一层，难读难维护 —— 回调地狱
    });
  });
});
```

回调地狱的三大问题：可读性差、错误处理分散、难以组合。Promise 与 async/await 正是为此而生。

## Promise：状态机

Promise 代表一个「进行中→成功/失败」的异步结果，有三种状态：`pending`（进行中）、`fulfilled`（已成功）、`rejected`（已失败），状态一旦确定不可逆转。

```js
const p = new Promise((resolve, reject) => {
  fetch('/api/user')
    .then(res => res.json())
    .then(data => resolve(data))
    .catch(err => reject(err));
});
```

### 链式调用

`then` 返回新的 Promise，可串联；`catch` 捕获链上任意一处的错误：

```js
fetchUser(id)
  .then(user => fetchProfile(user.id))
  .then(profile => render(profile))
  .catch(err => console.error('出错了', err));
```

### 常用静态方法

```js
Promise.all([p1, p2])             // 全部成功才 resolve，任一失败即 reject
Promise.allSettled([p1, p2])      // 全部结束（成功或失败）后才 resolve，不因某个失败中断
Promise.race([p1, p2])            // 谁先完成（成功或失败）就采用谁 —— 常用于超时控制
Promise.any([p1, p2])             // 第一个成功；全部失败才 reject
```

## async / await

`async` 函数返回 Promise；`await` 等待 Promise 结果，让异步代码像同步一样书写：

```js
async function loadUser() {
  try {
    const res = await fetch('/api/user');
    const user = await res.json();
    return user;
  } catch (err) {
    console.error('加载失败', err);
    return null;
  }
}
```

- `await` 只能在 `async` 函数内使用。
- 错误用 `try/catch` 捕获，等价于 promise 的 `.catch`。
- 多个无依赖的 await 可以并行：`await Promise.all([a(), b()])`，避免串行等待。

## 事件循环：宏任务与微任务

浏览器的事件循环持续从任务队列中取出任务执行。任务分两类：

- **宏任务（macrotask）**：整体脚本、`setTimeout`、`setInterval`、I/O、事件回调、UI 渲染。
- **微任务（microtask）**：`Promise.then/catch/finally`、`queueMicrotask`、`MutationObserver`。

**调度规则**：每轮循环先执行一个宏任务 → 清空所有微任务 → 渲染 UI → 取下一个宏任务。微任务永远先于下一个宏任务执行。

```js
console.log('A');
setTimeout(() => console.log('B'), 0);   // 宏任务
Promise.resolve().then(() => console.log('C')); // 微任务
console.log('D');
// 输出：A D C B
```

经典输出顺序推理题，按两套队列+循环规则即可推导，不必死记。

## 常见异步场景小结

| 场景 | 推荐工具 |
|:-----|:---------|
| 一次网络请求 | `fetch` + async/await + try/catch |
| 多个请求并行 | `Promise.all` / `Promise.allSettled` |
| 请求超时控制 | `Promise.race` + `setTimeout` |
| 定时轮询 | `setInterval` 或递归 `setTimeout` |
| 高频事件限流 | 防抖/节流（见第四阶段「常用工具函数」） |
