# JavaScript 语言基础

JavaScript（简称 JS）是浏览器的原生脚本语言，也是 Node.js 的底层语言。先掌握语法与数据类型，再进入函数、原型、异步等更深的概念。

## 变量声明：let / const / var

```js
let count = 0;        // 可变变量，块级作用域
const PI = 3.14;      // 常量，不可重新赋值，块级作用域
var old = 1;          // 旧式声明，函数级作用域 + 变量提升，日常不推荐
```

- **优先 const**，需要重新赋值时才用 let。
- `const` 保证的是「绑定不可变」，对象/数组内部仍可修改（除非冻结）。
- `let/const` 有**暂时性死区（TDZ）**：声明前访问会抛错；`var` 会被提升为 `undefined`。

```js
console.log(typeof x); // undefined（var 提升）
let y = 1; // 若在声明前写 console.log(y) 会报 ReferenceError
```

## 数据类型

**7 种原始类型 + 1 种引用类型：**

| 类型 | typeof 结果 | 示例 |
|:-----|:-----------|:-----|
| `string` | `"string"` | `"hi"`（建议用单引号或反引号） |
| `number` | `"number"` | `42`、`3.14`、`NaN`、`Infinity` |
| `boolean` | `"boolean"` | `true` / `false` |
| `undefined` | `"undefined"` | 未赋值 |
| `null` | `"object"`（历史遗留 bug） | 显式的「空」 |
| `symbol` | `"symbol"` | `Symbol()` |
| `bigint` | `"bigint"` | `9007199254740991n` |
| `object`（引用类型） | `"object"` | 对象、数组、函数、日期等 |

**判断类型的坑：**

```js
typeof null           // "object" —— 需要 null 判断用 === null
Array.isArray([])     // true —— 判断数组用这个，typeof [] 是 "object"
typeof (() => {})     // "function" —— 函数是特殊的对象
```

## 类型转换

```js
Number("42");      // 42
Number("abc");     // NaN
String(42);        // "42"
Boolean(0);        // false
!!"hello";         // true
parseInt("42px");  // 42
```

**真值 / 假值**：假值仅 6 个——`false`、`0`、`""`、`null`、`undefined`、`NaN`，其余全是真值。

## 运算符

```js
// 算术
5 + 3; 5 - 3; 5 * 3; 5 / 2; 5 % 2; 2 ** 3; // 8

// 比较；=== 严格相等（不转换类型），== 宽松相等（会转换，尽量别用）
1 === "1";  // false
1 == "1";   // true（隐式转换）
null === undefined; // false

// 逻辑：短路求值
true && doSomething();
false || "默认值";
const v = maybeNull ?? "兜底值";   // ?? 仅当左侧为 null/undefined 时取右侧

// 可选链
user?.profile?.name;  // 链上任意一层为 null/undefined 返回 undefined
```

`??`（空值合并）与 `||` 的关键区别：`0 || "x"` 得 `"x"`，`0 ?? "x"` 得 `0`。

## 流程控制

```js
if (score >= 90) {
  // ...
} else if (score >= 60) {
  // ...
} else {
  // ...
}

const grade = score >= 60 ? 'pass' : 'fail';  // 三元

switch (action) {
  case 'add': break;
  case 'del': break;
  default:
}

for (let i = 0; i < 10; i++) { /* ... */ }
let i = 0;
while (i < 10) { i++; }
do { /* 至少执行一次 */ } while (false);

for (const item of items) { /* 遍历可迭代对象（数组等） */ }
```

## 函数基础

```js
// 函数声明（有提升，可提前调用）
function add(a, b) {
  return a + b;
}

// 函数表达式
const sub = function (a, b) {
  return a - b;
};

// 箭头函数（无自己的 this/arguments，见 2.3）
const mul = (a, b) => a * b;
const greet = name => `hello ${name}`;
```

函数相关进阶（参数默认值、剩余参数、作用域、闭包）见 `2.2-函数作用域与闭包`。

## 严格模式

```js
'use strict';   // 文件或函数顶部声明
```

严格模式禁用了若干历史遗留的坏行为（如未声明直接赋值、给只读属性赋值、`delete` 不可删除属性等），模块与 class 内部默认就是严格模式。
