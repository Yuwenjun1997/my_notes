# 响应式与动画

响应式让网站在不同屏幕宽度下都可用；动画让交互更生动。两者都是现代前端的基础能力。

## 响应式核心思路

- **流式布局**：容器用百分比/弹性尺寸代替固定像素，内容随宽度自然流动。
- **弹性图片**：`img { max-width: 100%; height: auto; }` 防止图片撑破容器。
- **媒体查询**：按视口宽度切换样式。

## 媒体查询与断点

```css
/* 视口 ≥ 768px 时生效（tablet 及以上） */
@media (min-width: 768px) {
  .cards {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* 视口 ≤ 480px 时生效（手机） */
@media (max-width: 480px) {
  .nav {
    flex-direction: column;
  }
}
```

常用断点参考：`480px`（手机）→ `768px`（平板竖屏）→ `1024px`（平板横屏/小桌面）→ `1280px`（桌面）。断点不是硬性标准，按内容实际换行需求定。

### 移动优先 vs 桌面优先

- **移动优先**：默认样式面向手机，再用 `min-width` 逐级增强。代码更简洁、手机用户优先。
- **桌面优先**：默认桌面样式，用 `max-width` 降级适配。适合后台管理类系统。

## 自适应单位

- `rem`：基于根元素字号，整站字号体系改 `html { font-size }` 一处即可整体缩放。
- `vw` / `vh`：基于视口，常用于大屏占位与沉浸式字体。
- `clamp(min, 理想值, max)`：区间内自适应，无需媒体查询：

```css
.title {
  font-size: clamp(20px, 4vw, 40px);  /* 最小20px，随视口浮动，最大40px */
}
```

## 过渡 transition

`transition` 让属性变化平滑过渡，需要变化前后有明确值：

```css
.btn {
  background: #333;
  transition: background-color 0.3s ease, transform 0.3s ease;
}
.btn:hover {
  background: #0066ff;
  transform: translateY(-2px);
}
```

- 可过渡：颜色、尺寸、`transform`、`opacity` 等（连续数值）。
- `transition: 属性 时长 缓动函数 延迟`，多个属性用逗号分隔。
- 优化建议：尽量过渡 `transform` 与 `opacity`，它们不引发重排（reflow）。

## 动画 animation 与 @keyframes

```css
@keyframes bounce {
  from { transform: translateY(0); }
  50%  { transform: translateY(-12px); }
  to   { transform: translateY(0); }
}

.loading-dot {
  animation: bounce 0.6s ease-in-out infinite;
}
```

`animation` 简写：`名称 时长 缓动 延迟 次数(无限用 infinite)`。多个动画可用 `keyframes` 分帧控制。

### 示例：CSS 加载动画

```html
<div class="spinner"></div>
```

```css
.spinner {
  width: 32px;
  height: 32px;
  border: 3px solid rgba(0, 0, 0, 0.1);
  border-top-color: #0066ff;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}

@keyframes spin {
  to { transform: rotate(360deg); }
}
```

## transform 变换

| 函数 | 作用 |
|:-----|:-----|
| `translate(x, y)` | 平移 |
| `scale(n)` | 缩放 |
| `rotate(deg)` | 旋转 |
| `skew(deg)` | 斜切 |

变换不会改变元素占位，配合 `transition` 就能做出平滑的交互动效。

## 无障碍与性能要点

- 动效尊重系统偏好：`@media (prefers-reduced-motion: reduce)` 时降级为无动画或极简动画。
- 避免对会触发重排的属性（width/height/margin）做高频动画，改用 `transform`/`opacity`。
- 动画元素尽量加 `will-change` 或让 GPU 合成，避免页面卡顿。
