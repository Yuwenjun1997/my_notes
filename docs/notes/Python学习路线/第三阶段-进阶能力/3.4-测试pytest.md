# 测试 pytest

## 一、pytest 基础

### 3.4.1 安装与入门

**pytest**：Python 生态最流行的测试框架，断言简单、插件丰富、支持参数化。

```bash
# 安装（含常用插件）
pip install pytest pytest-asyncio pytest-cov
```

**基本测试用例**：

```python
# test_math.py
def add(a, b):
    return a + b

def test_add_positive():
    assert add(1, 2) == 3

def test_add_negative():
    assert add(-1, 1) == 0

def test_add_float():
    # ✅ pytest 用原生 assert，无需断言方法
    assert add(0.1, 0.2) == 0.30000000000000004
```

**运行测试**：

```bash
# 运行当前目录所有测试
pytest

# 指定文件 / 指定用例
pytest test_math.py
pytest test_math.py::test_add_negative

# 详细输出 + 显示打印
pytest -v -s

# 只运行失败的测试
pytest --lf

# 遇到第一个失败即停止
pytest -x
```

**断言与内建信息**：

```python
import pytest

def test_assertions():
    assert "py" in "python"
    assert [1, 2, 3] == [1, 2, 3]
    assert {"a": 1} == {"a": 1}

    # 异常断言：期待抛 ValueError
    with pytest.raises(ValueError, match="无效"):
        raise ValueError("参数无效")

    # 异常信息对象
    with pytest.raises(ValueError) as exc_info:
        raise ValueError("code=1001")
    assert "1001" in str(exc_info.value)

    # 条件断言：条件不满足时跳过
    if not has_feature():
        pytest.skip("功能未实现")
```

### 3.4.2 参数化与标记

**参数化（parametrize）**：一个用例跑多组数据。

```python
import pytest

@pytest.mark.parametrize("a,b,expected", [
    (1, 2, 3),
    (2, 3, 5),
    (10, 20, 30),
])
def test_add(a, b, expected):
    assert a + b == expected

# 组合参数（笛卡尔积）
@pytest.mark.parametrize("x", [0, 1])
@pytest.mark.parametrize("y", [1, 2])
def test_multi(x, y):
    assert x * y >= 0

# 为参数组指定 ID，便于定位失败用例
@pytest.mark.parametrize(
    "input,expected",
    [("abc", 3), ("hello world", 11)],
    ids=["three-chars", "eleven-chars"],
)
def test_len(input, expected):
    assert len(input) == expected
```

**标记（Mark）**：

```python
import pytest

@pytest.mark.slow          # 自定义标记
def test_slow_case():
    ...

@pytest.mark.skip(reason="功能未完成")  # 无条件跳过
def test_not_ready():
    ...

@pytest.mark.skipif(
    __import__("sys").platform == "win32",
    reason="Windows 不支持",
)  # 条件跳过
def test_unix_only():
    ...

@pytest.mark.xfail(reason="已知缺陷，期待失败")  # 预期失败
def test_known_bug():
    ...
```

```bash
# 只运行 fast 标记 / 跳过 slow 标记
pytest -m "fast"
pytest -m "not slow"
```

**注册自定义标记**（避免警告）：

```python
# pytest.ini
[pytest]
markers =
    slow: 慢速测试
    smoke: 冒烟测试
```

## 二、Fixture

### 3.4.3 Fixture 基础与作用域

**Fixture**：测试前准备、测试后清理的机制，pytest 自动注入。

```python
import pytest

@pytest.fixture
def user_data():
    # 准备阶段
    data = {"name": "张三", "age": 28}
    yield data          # yield 之前的代码：setup；之后：teardown
    # 清理阶段（测试结束后执行）
    data.clear()

def test_user(user_data):
    assert user_data["name"] == "张三"
```

**Fixture 作用域**：

| 作用域 | 生命周期 | 适用场景 |
|--------|---------|---------|
| `function`（默认） | 每个用例执行前后 | 独立数据 |
| `class` | 每个类执行前后 | 类级资源 |
| `module` | 每个模块执行前后 | 模块共享数据 |
| `session` | 整个测试会话 | 数据库连接、全局配置 |

```python
import pytest

@pytest.fixture(scope="session")
def db_conn():
    """整个测试会话只创建一次数据库连接"""
    conn = create_connection()
    yield conn
    conn.close()

@pytest.fixture(scope="module")
def test_data():
    return {"records": [1, 2, 3]}
```

**Fixture 之间依赖**：

```python
@pytest.fixture
def api_client(db_conn):
    """组合依赖：自动注入 db_conn"""
    return APIClient(db_conn)
```

### 3.4.4 conftest.py 与 yield fixture

**conftest.py**：放公共 fixture，pytest 自动发现，无需导入。

```python
# conftest.py
import pytest
from myapp.database import create_session

@pytest.fixture(scope="session")
def engine():
    # 使用独立测试库
    return create_engine("sqlite:///test.db")

@pytest.fixture
def session(engine):
    """每个测试独立事务，测试后回滚"""
    with create_session(engine) as s:
        yield s
        s.rollback()  # ✅ 回滚，保证测试相互隔离
```

**yield fixture 清理异常场景**：

```python
@pytest.fixture
def temp_file(tmp_path):
    """内置 tmp_path：pytest 自动创建并清理临时目录"""
    f = tmp_path / "data.txt"
    f.write_text("content")
    yield f
    # 临时目录由 pytest 自动清理
```

**内置 fixture 速查**：

| 内置 fixture | 用途 |
|-------------|------|
| `tmp_path` / `tmp_path_factory` | 临时目录/文件 |
| `capsys` | 捕获 stdout/stderr |
| `monkeypatch` | 动态修改属性、环境变量 |
| `request` | 获取当前用例信息、参数 |

## 三、Mock 与 Monkeypatch

### 3.4.5 unittest.mock

**Mock**：替换外部依赖（网络、数据库、第三方 API），让测试独立可重复。

```python
from unittest.mock import Mock, patch

# 方式一：patch 替换对象
@patch("myapp.service.send_email")
def test_send(mock_send_email):
    from myapp.service import notify_user
    notify_user("user@example.com")
    mock_send_email.assert_called_once_with("user@example.com")

# 方式二：with 上下文
def test_api_call():
    with patch("requests.get") as mock_get:
        mock_get.return_value.status_code = 200
        mock_get.return_value.json.return_value = {"ok": True}
        result = call_api()
        assert result["ok"] is True

# 方式三：Mock 返回值链
mock_resp = Mock()
mock_resp.status_code = 200
mock_resp.json.return_value = {"items": [1, 2, 3]}
```

**模拟外部请求，测试超时与异常**：

```python
from unittest.mock import patch
import pytest

def fetch_user(user_id):
    import requests
    resp = requests.get(f"https://api.example.com/users/{user_id}", timeout=3)
    resp.raise_for_status()
    return resp.json()

@patch("requests.get")
def test_fetch_user_success(mock_get):
    mock_get.return_value.json.return_value = {"id": 1, "name": "张三"}
    assert fetch_user(1)["name"] == "张三"

@patch("requests.get")
def test_fetch_user_network_error(mock_get):
    import requests
    mock_get.side_effect = requests.exceptions.Timeout("超时")
    with pytest.raises(requests.exceptions.Timeout):
        fetch_user(1)
```

### 3.4.6 AsyncMock 与 monkeypatch

**AsyncMock**：模拟异步函数。

```python
from unittest.mock import AsyncMock, patch
import pytest

@pytest.mark.asyncio
@patch("myapp.service.fetch_async", new_callable=AsyncMock)
async def test_async_service(mock_fetch):
    mock_fetch.return_value = {"status": "ok"}

    from myapp.service import get_status
    result = await get_status()
    assert result["status"] == "ok"
```

**monkeypatch 修改环境与属性**：

```python
def test_env(monkeypatch):
    # 设置环境变量
    monkeypatch.setenv("DEBUG", "true")
    import os
    assert os.environ["DEBUG"] == "true"

    # 修改对象属性
    monkeypatch.setattr(MyClass, "MAX_RETRY", 5)

    # 删除属性
    monkeypatch.delenv("TOKEN", raising=False)
```

**mock 一个时间依赖的函数**：

```python
def is_expired(expire_at):
    from datetime import datetime
    return datetime.now() > expire_at

def test_is_expired(monkeypatch):
    from datetime import datetime
    # ✅ 固定时间，测试可复现
    monkeypatch.setattr(
        "myapp.utils.datetime",
        datetime,  # 需要统一导入方式
    )
```

## 四、异步与 FastAPI 测试

### 3.4.7 pytest-asyncio

**异步测试**：`pytest.mark.asyncio` 标记异步用例。

```python
import pytest

@pytest.mark.asyncio
async def test_async_add():
    async def add(a, b):
        return a + b
    assert await add(1, 2) == 3

# 全局配置：所有 async 用例自动运行
# pytest.ini
# [pytest]
# asyncio_mode = auto
```

**异步 Fixture**：

```python
import pytest
import redis.asyncio as aioredis

@pytest.fixture
async def redis_client():
    r = aioredis.Redis(decode_responses=True)
    yield r
    await r.aclose()
```

### 3.4.8 FastAPI TestClient

**同步测试**：用 TestClient 直接调用 FastAPI 应用。

```python
from fastapi.testclient import TestClient
from app.main import app

client = TestClient(app)

def test_create_user():
    resp = client.post("/users", json={"name": "张三", "email": "z@example.com"})
    assert resp.status_code == 200
    assert resp.json()["name"] == "张三"

def test_get_user_not_found():
    resp = client.get("/users/999")
    assert resp.status_code == 404

def test_requires_auth():
    # 未携带 token 应 401
    resp = client.get("/profile")
    assert resp.status_code == 401
```

**异步 httpx ASGI 测试**：

```python
import pytest
import httpx

@pytest.mark.asyncio
async def test_async_httpx():
    from app.main import app
    async with httpx.AsyncClient(
        transport=httpx.ASGITransport(app=app),
        base_url="http://test",
    ) as client:
        resp = await client.post("/users", json={"name": "李四"})
        assert resp.status_code == 200
```

**模拟认证用户**：

```python
from fastapi.testclient import TestClient
import pytest

def test_authorized(monkeypatch):
    from app.auth import get_current_user
    from app.main import app

    # 用依赖覆盖：直接返回测试用户，绕过 JWT 验证
    async def fake_get_current_user():
        return {"id": 1, "role": "admin"}

    app.dependency_overrides[get_current_user] = fake_get_current_user
    client = TestClient(app)

    resp = client.get("/admin/users")
    assert resp.status_code == 200

    # 清理覆盖
    app.dependency_overrides.clear()
```

## 五、覆盖率与测试策略

### 3.4.9 pytest-cov 覆盖率

**覆盖率**：衡量代码被测试到的比例。

```bash
# 生成覆盖率报告（终端）
pytest --cov=myapp --cov-report=term-missing

# 生成 HTML 报告
pytest --cov=myapp --cov-report=html

# 覆盖率低于阈值则失败
pytest --cov=myapp --cov-fail-under=80
```

```python
# 忽略不需要覆盖的代码
if __name__ == "__main__":  # pragma: no cover
    app.run()
```

### 3.4.10 数据库测试与工厂

**使用测试库 + 事务回滚**：

```python
# conftest.py
import pytest
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker

@pytest.fixture(scope="session")
def engine():
    # ✅ 使用独立的 SQLite 测试库
    return create_engine("sqlite:///:memory:")

@pytest.fixture
def db_session(engine):
    """每个用例独立事务，结束回滚，互不污染"""
    connection = engine.connect()
    transaction = connection.begin()
    Session = sessionmaker(bind=connection)
    session = Session()
    yield session
    session.close()
    transaction.rollback()
    connection.close()
```

**factory_boy 数据工厂**：

```python
# factories.py
import factory
from myapp.models import User

class UserFactory(factory.Factory):
    class Meta:
        model = User

    name = "张三"
    email = factory.Sequence(lambda n: f"user{n}@example.com")
    age = factory.Faker("random_int", min=18, max=60)

# test 中使用
def test_user(user_factory):
    user = UserFactory.create()   # 快速创建实例
    assert "@example.com" in user.email
```

**测试金字塔**：

```
        /\           端到端测试（少）
       /  \          集成测试（中）
      /    \        单元测试（多，核心）
     /______\
```

**测试策略建议**：
- 大量快速单元测试（不依赖外部服务）
- 适量集成测试（真实 DB、Redis，用测试环境）
- 少量端到端冒烟测试（关键链路）
- 外部服务（第三方 API）一律 mock

## 实践项目

### 目标

为 2.2 中的**待办事项 API** 编写完整测试套件：覆盖 CRUD 接口、认证逻辑、异常分支，使用 fixture 隔离数据库、mock 外部依赖，并保证覆盖率不低于 85%。

### 步骤

1. 搭建 `tests/` 目录，配置 `conftest.py`（测试库、client fixture）
2. 用 `dependency_overrides` 模拟认证用户
3. 为待办 CRUD 编写接口测试（成功 + 404 + 鉴权失败）
4. 用 `parametrize` 覆盖非法输入（空标题、超长、非法状态）
5. mock 外部依赖（邮件、支付），测试异常路径
6. 用 `pytest --cov` 查看覆盖率，补充缺口用例到 85% 以上
