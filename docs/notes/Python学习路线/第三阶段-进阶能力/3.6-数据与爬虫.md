# 数据与爬虫

## 一、数据采集基础

### 3.6.1 HTTP 请求库

**采集流程**：发送请求 → 获取响应 → 解析提取 → 清洗存储。

| 库 | 特点 | 适用场景 |
|-----|------|---------|
| `urllib` | 标准库内置 | 极简需求 |
| `requests` | 简单易用、生态成熟 | 同步采集首选 |
| `httpx` | 支持同步/异步、HTTP/2 | 异步采集、现代项目 |
| `aiohttp` | 异步、高性能 | 大规模并发采集 |

**requests 使用**：

```python
import requests

# GET 请求
resp = requests.get("https://example.com", timeout=10)
print(resp.status_code)          # 状态码
print(resp.headers.get("content-type"))
print(resp.encoding)             # 编码

# 自定义请求头（模拟浏览器）
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...",
    "Accept-Language": "zh-CN,zh;q=0.9",
}
resp = requests.get(url, headers=headers, timeout=10)

# POST + JSON
resp = requests.post("https://api.example.com/login",
                     json={"username": "admin", "password": "xxx"},
                     timeout=10)

# 会话保持 Cookie（登录状态）
with requests.Session() as s:
    s.post("https://example.com/login", data={...})
    resp = s.get("https://example.com/profile")  # 自动携带 Cookie
```

**httpx 异步采集**：

```python
import asyncio
import httpx

async def fetch_all(urls: list[str]) -> list:
    async with httpx.AsyncClient(timeout=10, follow_redirects=True) as client:
        # 并发请求多个 URL
        tasks = [client.get(url) for url in urls]
        responses = await asyncio.gather(*tasks)
        return [r.json() for r in responses if r.status_code == 200]

async def main():
    urls = [f"https://api.example.com/page/{i}" for i in range(10)]
    data = await fetch_all(urls)
    print(f"成功获取 {len(data)} 个页面")

asyncio.run(main())
```

**异常处理与重试**：

```python
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

# ✅ 自动重试：网络错误 + 5xx + 429
retry = Retry(
    total=3,                        # 最多重试 3 次
    backoff_factor=1,               # 退避时间 1,2,4 秒
    status_forcelist=[500, 502, 503, 429],
)
adapter = HTTPAdapter(max_retries=retry)

session = requests.Session()
session.mount("https://", adapter)
session.mount("http://", adapter)

try:
    resp = session.get(url, timeout=10)
    resp.raise_for_status()         # 非 2xx 抛异常
except requests.exceptions.Timeout:
    print("请求超时")
except requests.exceptions.ConnectionError:
    print("连接失败")
except requests.exceptions.HTTPError:
    print(f"HTTP 错误：{resp.status_code}")
```

### 3.6.2 BeautifulSoup 与 lxml

**解析库对比**：

| 库 | 性能 | 语法 | 适用场景 |
|-----|:---:|------|---------|
| `BeautifulSoup4` | 中 | 简单直观、容错强 | 通用解析首选 |

```bash

```

**BeautifulSoup 解析**：

```python
from bs4 import BeautifulSoup

html = """
<html><body>
  <div class="article" data-id="101">
    <h2>Python 爬虫教程</h2>
    <p class="desc">实用的爬虫指南</p>
    <a href="/detail/101">阅读全文</a>
    <span class="tag">爬虫</span>
    <span class="tag">Python</span>
  </div>
</body></html>
"""

# 解析（lxml 解析器更快）
soup = BeautifulSoup(html, "lxml")

# 查找单个元素
title = soup.find("h2").text                    # Python 爬虫教程
desc = soup.select_one(".desc").text            # CSS 选择器

# 查找多个元素
tags = [t.text for t in soup.select(".tag")]    # ['爬虫', 'Python']

# 属性访问
div = soup.find("div", class_="article")
print(div["data-id"])                           # 101
print(div.find("a")["href"])                    # /detail/101

# 嵌套查找
text = soup.select_one(".article h2").text
```

**lxml XPath 解析**：

```python
from lxml import etree

html = etree.HTML(raw_html)                     # 解析 HTML
# XPath 定位
titles = html.xpath("//div[@class='article']//h2/text()")
links = html.xpath("//div[@class='article']/a/@href")

# 常用 XPath
# //div                 所有 div
# //div[@class="x"]     class 为 x 的 div
# //a/@href             a 的 href 属性
# text()                节点文本
# ../../../              向上回溯
```

**CSS 选择器 vs XPath**：

| 需求 | CSS | XPath |
|------|-----|-------|
| class 选择 | `.desc` | `//*[@class="desc"]` |
| id 选择 | `#main` | `//*[@id="main"]` |
| 属性存在 | `[data-id]` | `//*[@data-id]` |
| 文本包含 | `:contains()`(非标准) | `//p[contains(text(),"词")]` |

## 三、动态页面采集

### 3.6.3 Selenium 与 Playwright

**动态页面**：内容由 JavaScript 渲染，普通 requests 拿不到数据。

| 方案 | 优点 | 缺点 |
|------|------|------|
| 接口逆向 | 性能最好 | 需分析 XHR 请求 |
| **Playwright** | 现代、自动等待、多浏览器 | 较重 |
| **Selenium** | 生态老、文档多 | 启动慢、维护成本高 |

**Playwright 入门**：

```bash
pip install playwright
playwright install chromium    # 安装浏览器
```

```python
import asyncio
from playwright.async_api import async_playwright

async def scrape_dynamic(url: str):
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()

        # ✅ 智能等待：等待元素出现（自动处理渲染时序）
        await page.goto(url, wait_until="networkidle")
        await page.wait_for_selector(".product-list")

        # 提取数据
        items = await page.query_selector_all(".product")
        for item in items[:5]:
            title = await item.query_selector(".name")
            print(await title.inner_text())

        # 执行 JS 获取数据
        data = await page.evaluate("() => window.__INITIAL_STATE__")
        await browser.close()

asyncio.run(scrape_dynamic("https://example.com/list"))
```

**Playwright 常用操作**：

```python
# 表单交互
await page.fill("#username", "admin")
await page.click("button[type=submit]")

# 等待与拦截
await page.wait_for_load_state("networkidle")   # 网络空闲
await page.screenshot(path="shot.png")

# 拦截响应，读取接口数据
async def handle_response(response):
    if "/api/list" in response.url:
        data = await response.json()
        print(data)
page.on("response", handle_response)
```

**Selenium vs Playwright 对比**：

| 对比维度 | Playwright | Selenium |
|---------|:---:|:---:|
| 安装 | 一条命令装浏览器 | 需单独下载驱动 |
| 自动等待 | ✅ 内置 Web 优先 | 需显式 WebDriverWait |
| 异步支持 | ✅ 原生 async | ❌ 同步为主 |
| 多浏览器 | Chromium/Firefox/WebKit | 更全（含 Safari） |
| 维护活跃度 | 高 | 中 |

## 四、反爬与合规

### 3.6.4 常见反爬与应对

**常见反爬手段**：

| 反爬手段 | 表现 | 应对策略 |
|---------|------|---------|
| UA 检测 | 拒绝非浏览器 UA | 伪装真实浏览器 UA |
| 频率限制 | 请求过多封 IP | 限速、代理池 |
| IP 封禁 | 短时间大量请求 | 代理 IP、分布式 |
| JS 渲染 | 数据由 JS 生成 | Playwright 渲染 |
| 验证码 | 登录/查询需验证码 | 识别或人工（谨慎） |
| 请求签名 | 参数需加密签名 | 逆向 JS（有合规风险） |

**降低被反爬概率的规范做法**：

```python
import requests
import time
from random import uniform

headers = {
    "User-Agent": "Mozilla/5.0 ...",
    "Referer": "https://example.com/",
}

for i in range(100):
    resp = requests.get(f"{url}/{i}", headers=headers, timeout=10)
    # ✅ 遵守道德爬虫：随机间隔，控制频率
    time.sleep(uniform(0.5, 1.5))

    # 频率控制：批量请求时统一限速
    if i % 10 == 0:
        time.sleep(3)
```

**代理池使用**：

```python
proxies = {
    "http": "http://user:pass@proxy.example.com:8080",
    "https": "http://user:pass@proxy.example.com:8080",
}
resp = requests.get(url, proxies=proxies, timeout=10)

# 轮换代理，降低单 IP 压力
import random
proxy_list = [...]  # 从代理池获取
resp = requests.get(url, proxies={"http": random.choice(proxy_list)})
```

### 3.6.5 爬虫合规红线

**道德与法律约束**：

| 原则 | 说明 |
|------|------|
| **遵守 robots.txt** | 读取并遵循网站的爬虫协议 |
| **控制请求频率** | 不冲击对方服务器 |
| **尊重版权** | 不爬取并分发受版权保护的内容 |
| **个人数据** | 遵守《个人信息保护法》等法规 |
| **不绕过技术保护** | 不破解登录、验证码、加密 |

```python
# 读取 robots.txt
import requests
from urllib.robotparser import RobotFileParser

rp = RobotFileParser()
rp.set_url("https://example.com/robots.txt")
rp.read()

# ✅ 采集前检查是否被允许
if rp.can_fetch("*", "https://example.com/list"):
    print("允许采集")
else:
    print("被 robots.txt 禁止，放弃")
```

    # 1. 去重
    df = df.drop_duplicates(subset=["url"])

    # 2. 去除空白字符
    df["title"] = df["title"].str.strip()

    # 3. 类型转换
    df["views"] = pd.to_numeric(df["views"], errors="coerce")

    # 4. 清洗异常值
    df = df[df["views"] >= 0]

    # 5. 处理缺失

    return df

**采集 → 分析 → 导出的完整流程**：

```python
import requests
import pandas as pd
from bs4 import BeautifulSoup

def scrape_news(url):
    resp = requests.get(url, timeout=10)
    soup = BeautifulSoup(resp.text, "lxml")

    records = []
    for item in soup.select(".news-item"):
        records.append({
            "title": item.select_one(".title").text.strip(),
            "date": item.select_one(".date").text.strip(),
            "link": item.find("a")["href"],
        })
    return pd.DataFrame(records)

def main():
    df = scrape_news("https://example.com/news")
    df["date"] = pd.to_datetime(df["date"])
    daily_count = df.groupby(df["date"].dt.date).size()
    daily_count.plot(kind="line", title="每日新闻数量")
    df.to_csv("news.csv", index=False, encoding="utf-8-sig")

if __name__ == "__main__":
    main()
```

## 实践项目

### 目标

实现一个**静态站点文章采集分析器**：爬取一个列表页的所有文章标题、链接、发布日期与阅读量，进行数据清洗与统计分析，并输出可视化报告。

### 步骤

1. 选定目标（如公开的博客/资讯站），先检查 `robots.txt` 确认合规
2. 用 `requests + BeautifulSoup` 采集列表页与详情页数据
3. 数据清洗：去重、去除空白、类型转换、缺失值处理
4. 用 pandas 做分组聚合（按日期/分类统计发布量）
5. 用 matplotlib 生成柱状图与折线图报告
6. 导出 CSV（UTF-8-BOM）与 Excel 结果
