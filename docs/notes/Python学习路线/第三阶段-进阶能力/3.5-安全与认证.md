# 安全与认证

## 一、Web 安全基础

### 3.5.1 OWASP 常见漏洞

**OWASP Top 10**：Web 应用最危险的十大安全风险，是安全防御的纲领。

| 漏洞 | 危害 | 防御要点 |
|------|------|---------|
| **SQL 注入** | 数据库数据泄露/篡改 | 参数化查询、ORM 禁止拼接 |
| **XSS 跨站脚本** | 窃取 Cookie、会话劫持 | 输出转义、CSP 头 |
| **CSRF 跨站请求伪造** | 诱导用户执行操作 | CSRF Token、SameSite Cookie |
| **SSRF 服务端请求伪造** | 访问内网资源 | URL 白名单、限制重定向 |
| **文件上传漏洞** | 上传恶意文件执行 | 校验类型/大小、存储分离 |
| **认证缺陷** | 弱口令、暴力破解 | 强密码策略、限流 |
| **越权访问** | 访问他人数据 | 对象级权限校验 |

**SQL 注入防御**：

```python
# ❌ 危险：字符串拼接 SQL
def get_user_unsafe(username):
    sql = f"SELECT * FROM users WHERE name = '{username}'"
    return execute(sql)

# ✅ 安全：参数化查询（SQLAlchemy）
def get_user_safe(username):
    from sqlalchemy import text
    result = db.execute(
        text("SELECT * FROM users WHERE name = :name"),
        {"name": username},  # 参数绑定，杜绝注入
    )
    return result.fetchone()
```

**XSS 输出转义**（Jinja2 默认自动转义）：

```python
from fastapi import FastAPI
from fastapi.responses import HTMLResponse
from starlette.templating import Jinja2Templates

templates = Jinja2Templates(directory="templates")

# Jinja2 中 {{ user_input }} 默认 HTML 转义，避免 XSS
# 需要输出原始 HTML 时用 |safe，但必须确保内容可信
# <p>{{ user_input }}</p>          # ✅ 自动转义
# <p>{{ user_input|safe }}</p>     # ⚠️ 慎用，仅可信内容
```

**CSRF 防护**（FastAPI + 前端框架通常用 CORS + SameSite）：

```python
# 关键：Cookie 设置 SameSite，阻止跨站请求携带
from fastapi import FastAPI
from starlette.middleware.sessions import SessionMiddleware

app = FastAPI()
# SameSite=lax/strict 阻止跨站请求自动携带 Cookie
app.add_middleware(
    SessionMiddleware,
    secret_key="your-secret-key",
    session_cookie="session",
    https_only=True,   # 生产强制 HTTPS
    same_site="lax",
)
```

## 二、密码安全

### 3.5.2 加盐哈希

**原则**：
- 绝不明文存储密码
- 绝不使用 MD5/SHA1 直接存储（已被暴力破解）
- 使用慢哈希算法 + 随机盐

```bash
pip install passlib[bcrypt]
```

**bcrypt / argon2 正确用法**：

```python
from passlib.hash import bcrypt

# 注册：哈希密码
def hash_password(plain: str) -> str:
    # ✅ 自动生成随机盐，包含在哈希串中
    return bcrypt.hash(plain)

# 登录：校验密码
def verify_password(plain: str, hashed: str) -> bool:
    return bcrypt.verify(plain, hashed)

# 使用示例
hashed = hash_password("my_secret_123")
print(hashed)   # $2b$12$...（含盐 + 迭代次数）
print(verify_password("my_secret_123", hashed))  # True
print(verify_password("wrong", hashed))          # False
```

**算法对比**：

| 算法 | 特点 | 推荐场景 |
|------|------|---------|
| `bcrypt` | 内置盐、可调成本因子 | ✅ 通用首选 |
| `argon2` | 抗 GPU 暴力破解，内存困难 | ✅ 高安全需求 |
| `pbkdf2_sha256` | 标准库内置（hashlib） | 无第三方依赖时 |
| MD5/SHA1 | 快速但易破解 | ❌ 禁止存密码 |

**密码存储最佳实践**：
- 成本因子不宜过高（登录体验）也不宜过低（安全）
- 登录失败统一返回"用户名或密码错误"，避免用户枚举
- 登录接口限流，防止暴力破解

## 三、JWT 详解

### 3.5.3 JWT 结构

**JWT（JSON Web Token）**：无状态认证令牌，由三段组成。

```
Header.Payload.Signature
eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxIn0.xxxxxxxxxxxx

Header（头部）    ：算法类型，如 {"alg":"HS256","typ":"JWT"}
Payload（负载）   ：声明数据，如 {"sub":"1","exp":1750000000}
Signature（签名） ：防止篡改，HS256(secret, Header.Payload)
```

**PyJWT 生成与验证**：

```python
pip install PyJWT
```

```python
import jwt
from datetime import datetime, timedelta, timezone

SECRET_KEY = "your-very-secret-key"
ALGORITHM = "HS256"

def create_access_token(user_id: int, expires_minutes: int = 30) -> str:
    payload = {
        "sub": str(user_id),                    # subject 用户标识
        "exp": datetime.now(timezone.utc) + timedelta(minutes=expires_minutes),
        "iat": datetime.now(timezone.utc),      # 签发时间
        "role": "user",                          # 自定义声明
    }
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)

def decode_token(token: str) -> dict:
    try:
        # ✅ 自动校验签名与过期时间
        return jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
    except jwt.ExpiredSignatureError:
        raise ValueError("令牌已过期")
    except jwt.InvalidTokenError:
        raise ValueError("令牌无效")
```

**JWT 刷新机制**：

| 令牌 | 有效期 | 用途 |
|------|:---:|------|
| Access Token | 短（15min-2h） | 访问受保护接口 |
| Refresh Token | 长（7-30天） | 换取新的 Access Token |

```python
def create_refresh_token(user_id: int) -> str:
    payload = {
        "sub": str(user_id),
        "exp": datetime.now(timezone.utc) + timedelta(days=7),
        "type": "refresh",
    }
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)

def refresh_access_token(refresh_token: str) -> str:
    payload = decode_token(refresh_token)
    if payload.get("type") != "refresh":
        raise ValueError("非刷新令牌")
    return create_access_token(int(payload["sub"]))
```

**JWT 使用注意事项**：
- 密钥必须保密且足够长（>= 32 字符）
- 敏感数据不要放入 Payload（可被 Base64 解码，仅签名防篡改）
- 生产环境用 HTTPS 传输，防止中间人窃取
- 退出登录需黑名单/短有效期（无状态令牌无法主动撤销）

## 四、OAuth2 授权模式

### 3.5.4 OAuth2 四种授权模式

**OAuth2**：授权框架，让用户授权第三方应用访问其资源。

| 模式 | 适用场景 | 说明 |
|------|---------|------|
| **授权码模式** | Web 应用（推荐） | 最安全，code 换 token |
| **隐式模式** | SPA 前端（已不推荐） | 直接返回 token |
| **密码模式** | 信任的一方应用 | 直接用户名密码换 token |
| **客户端凭证** | 服务间调用 | 以应用身份访问 |

**授权码模式流程**：

```text
用户 → 第三方App → 授权服务器 → 用户登录授权
  │                                 │
  │        返回授权码 code           │
  ├─────────────────────────────────┘
  │
  │ 用 code + client_secret 换 token
  └──────────────────→ 授权服务器 → 返回 Access Token
```

### 3.5.5 FastAPI Security

**FastAPI 内置 OAuth2 密码模式支持**：

```python
from fastapi import FastAPI, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from passlib.hash import bcrypt

app = FastAPI()

# tokenUrl：前端用它换 token 的登录接口
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/token")

# 模拟用户存储
fake_users = {
    "zhangsan": {"username": "zhangsan", "password": bcrypt.hash("secret123"), "role": "user"},
}

def verify_user(username: str, password: str) -> dict:
    user = fake_users.get(username)
    if not user or not bcrypt.verify(password, user["password"]):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="用户名或密码错误",
        )
    return user

@app.post("/token")
async def login(form: OAuth2PasswordRequestForm = Depends()):
    user = verify_user(form.username, form.password)
    token = create_access_token(int(user["id"]))
    return {"access_token": token, "token_type": "bearer"}

# 依赖：从请求头解析并校验 token
async def get_current_user(token: str = Depends(oauth2_scheme)) -> dict:
    try:
        payload = decode_token(token)
    except ValueError as e:
        raise HTTPException(status_code=401, detail=str(e))
    user = fake_users.get(payload["sub"])
    if user is None:
        raise HTTPException(status_code=401, detail="用户不存在")
    return user

@app.get("/profile")
async def get_profile(current_user: dict = Depends(get_current_user)):
    return {"user": current_user["username"], "role": current_user["role"]}
```

**角色权限控制**：

```python
from functools import wraps

def require_role(role: str):
    def dependency(current_user: dict = Depends(get_current_user)):
        if current_user["role"] != role:
            raise HTTPException(status_code=403, detail="权限不足")
        return current_user
    return dependency

@app.get("/admin")
async def admin_only(user: dict = Depends(require_role("admin"))):
    return {"message": "管理员接口"}
```

## 五、生产安全加固

### 3.5.6 安全响应头与限速

**安全响应头**：

```python
from starlette.middleware.base import BaseHTTPMiddleware

class SecurityHeadersMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        response = await call_next(request)
        # ✅ 关键安全响应头
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["X-Frame-Options"] = "DENY"
        response.headers["Referrer-Policy"] = "no-referrer"
        response.headers["X-XSS-Protection"] = "1; mode=block"
        response.headers["Content-Security-Policy"] = "default-src 'self'"
        response.headers["Strict-Transport-Security"] = "max-age=31536000"
        return response
```

**CORS 严格配置**：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    # ❌ 生产环境不要用 "*"
    allow_origins=["https://admin.example.com"],  # ✅ 明确白名单
    allow_credentials=True,
    allow_methods=["GET", "POST", "PUT", "DELETE"],
    allow_headers=["Authorization", "Content-Type"],
)
```

**速率限制**：防止暴力破解与资源滥用。

```python
from fastapi import FastAPI, Request, HTTPException
import time

# 简易内存限流：每 IP 每分钟最多 N 次
rate_limits = {}

def rate_limit(key: str, limit: int = 60, window: int = 60):
    now = time.time()
    window_key = int(now // window)
    bucket_key = f"{key}:{window_key}"

    bucket = rate_limits.get(bucket_key, {"count": 0, "start": now})
    if bucket["start"] < now - window:
        bucket = {"count": 0, "start": now}

    bucket["count"] += 1
    rate_limits[bucket_key] = bucket
    if bucket["count"] > limit:
        raise HTTPException(status_code=429, detail="请求过于频繁")

@app.post("/login")
async def login(request: Request):
    client_ip = request.client.host
    rate_limit(f"login:{client_ip}", limit=5)   # 每分钟最多 5 次尝试
    ...
```

> 生产环境推荐使用 **Redis 分布式限流**（见 3.2 缓存模块）或 **slowapi** 库，内存限流在多个进程/实例间不共享。

**安全配置检查清单**：

| 项目 | 要求 |
|------|------|
| 传输层 | 强制 HTTPS（HSTS） |
| 密钥 | 环境变量注入，不入代码库 |
| 数据库 | 参数化查询、最小权限账号 |
| 日志 | 不记录密码/token 等敏感信息 |
| 依赖 | 定期 `pip-audit` 扫描漏洞 |
| 认证 | 限流 + 强密码 + 会话过期 |

实现一个**用户注册登录系统**：密码加盐哈希存储、JWT 登录与刷新、角色权限控制、登录限流与安全响应头，并用 pytest 验证安全边界。

3. 实现 `/token` 登录接口（OAuth2 密码模式）+ JWT 签发
4. 实现 `/refresh` 刷新接口与 `/profile` 受保护接口

7. 用 pytest 验证：错误密码、过期 token、权限不足、暴力破解被限流
