# 数据分析与可视化

## 一、pandas 数据处理进阶

### 2.1 数据读取与概览

pandas 是 Python 数据分析的核心库，`DataFrame` 是二维表结构。采集到的数据通常先落成 CSV/JSON，再读入分析。

```bash
pip install pandas matplotlib seaborn plotly openpyxl
```

```python
import pandas as pd

# 读取 CSV（指定编码，中文文件常见 utf-8 / gbk）
df = pd.read_csv("books.csv", encoding="utf-8")

# 读取 JSON
# df = pd.read_json("books.json")

# 读取 Excel（需要 openpyxl）
# df = pd.read_excel("books.xlsx", sheet_name="Sheet1")

# 数据概览
print(df.shape)        # (行数, 列数)
print(df.info())       # 每列的非空值数量与类型
print(df.head())       # 前 5 行
print(df.describe())   # 数值列的统计摘要（均值/标准差/分位数）
```

**常用字段操作**

```python
# 选取列（单列返回 Series，多列返回 DataFrame）
df["price"]                     # 单列
df[["title", "price", "rating"]]  # 多列

# 新增列：价格翻倍列
df["price_double"] = df["price"] * 2

# 删除列 / 行
df = df.drop(columns=["url"])       # 删列
df = df.drop(index=[0, 1])          # 按索引删行

# 重命名列
df = df.rename(columns={"name": "title"})
```

### 2.2 数据清洗

真实数据几乎都有**缺失、重复、异常**三类问题。

**缺失值处理**

```python
# 查看每列缺失数量
print(df.isnull().sum())

# 方案一：删除含缺失值的行
df_clean = df.dropna()

# 方案二：用固定值/均值填充
df["rating"].fillna("N/A", inplace=True)     # 分类字段用固定值
df["price"].fillna(df["price"].mean(), inplace=True)  # 数值字段用均值

# 方案三：向前/向后填充（时间序列常用）
df["price"].ffill()   # 用上一个值填充
df["price"].bfill()   # 用下一个值填充
```

**重复值处理**

```python
# 统计重复行
print(df.duplicated().sum())

# 删除完全重复的行
df = df.drop_duplicates()

# 按指定列去重，保留最后一条
df = df.drop_duplicates(subset=["title"], keep="last")
```

**异常值处理**：用 IQR（四分位距）识别离群点

```python
# 计算 IQR
Q1 = df["price"].quantile(0.25)
Q3 = df["price"].quantile(0.75)
IQR = Q3 - Q1

# 下界与上界
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

# 标记并过滤异常值
outliers = df[(df["price"] < lower) | (df["price"] > upper)]
print(f"异常值数量: {len(outliers)}")
df = df[(df["price"] >= lower) & (df["price"] <= upper)]
```

### 2.3 分组聚合与数据透视

**groupby 聚合**

```python
# 按评分分组，统计价格均值与图书数量
stats = df.groupby("rating").agg(
    平均价格=("price", "mean"),
    图书数量=("title", "count"),
    价格总和=("price", "sum"),
)
print(stats)
```

**数据透视表 pivot_table**

```python
# 行=类别，列=评分，值=平均价格
pivot = pd.pivot_table(
    df,
    values="price",
    index="category",
    columns="rating",
    aggfunc="mean",
    fill_value=0,        # 空值填 0
)
print(pivot)
```

**pivot 与 groupby 对比**

| 维度 | groupby | pivot_table |
|:-----|:--------|:------------|
| 结果形态 | 一维分组 | 二维交叉表 |
| 适用场景 | 简单分组统计 | 行/列双维度透视 |
| 常见配合 | `agg` 多个聚合 | `aggfunc` + `fill_value` |

## 二、时间序列分析

### 2.4 时间类型与 resample

分析采集到的带时间戳数据（如销售、日志）需要先转成 `datetime` 类型。

```python
# 转换时间列
df["created_at"] = pd.to_datetime(df["created_at"])

# 提取时间分量
df["year"] = df["created_at"].dt.year
df["month"] = df["created_at"].dt.month
df["weekday"] = df["created_at"].dt.day_name()

# 设置为索引后，可以按时间切片
df = df.set_index("created_at")
# 只保留 2026 年 6 月的数据
june = df["2026-06"]
```

**resample 重采样**：把数据聚合到新的时间粒度

```python
# 按天统计订单数
daily = df.resample("D").size()
# 按周统计销售额
weekly_sales = df["amount"].resample("W").sum()
# 按月求平均价格
monthly_avg = df["price"].resample("M").mean()

print(weekly_sales)
```

**常用重采样频率**

| 频率代码 | 含义 |
|:-----|:-----|
| `D` | 按天 |
| `W` | 按周 |
| `M` | 按月 |
| `Q` | 按季度 |
| `Y` | 按年 |
| `H` | 按小时 |

## 三、数据可视化

### 2.5 matplotlib 深入

matplotlib 是底层绘图库，所有图表都在 `Figure`（画布）+ `Axes`（坐标系）上绘制。

**解决中文乱码**

```python
import matplotlib
import matplotlib.pyplot as plt

# 设置中文字体（Windows 用 SimHei / Microsoft YaHei）
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False   # 解决负号显示为方块
```

**单图绘制**

```python
# 柱状图：各分类图书数量
category_count = df["category"].value_counts()
plt.figure(figsize=(10, 6))
plt.bar(category_count.index, category_count.values, color="#4C72B0")
plt.title("各分类图书数量")
plt.xlabel("分类")
plt.ylabel("数量")
plt.xticks(rotation=45)      # 横轴文字旋转 45°，避免重叠
plt.tight_layout()           # 自动调整间距
plt.savefig("category_bar.png", dpi=150)   # 保存高清图
plt.show()
```

**子图布局 subplots**

```python
# 2 行 2 列子图
fig, axes = plt.subplots(2, 2, figsize=(12, 8))

# 左上：价格分布直方图
axes[0, 0].hist(df["price"], bins=20, color="#55A868")
axes[0, 0].set_title("价格分布")

# 右上：评分占比饼图
rating_pct = df["rating"].value_counts(normalize=True) * 100
axes[0, 1].pie(rating_pct.values, labels=rating_pct.index, autopct="%.1f%%")
axes[0, 1].set_title("评分占比")

# 左下：折线图（按天订单趋势）
axes[1, 0].plot(daily.index, daily.values, color="#C44E52")
axes[1, 0].set_title("每日订单趋势")

# 右下：散点图（价格 vs 评分）
axes[1, 1].scatter(df["price"], df["rating"], alpha=0.5)
axes[1, 1].set_title("价格 vs 评分")

plt.tight_layout()
plt.savefig("dashboard.png", dpi=150)
plt.show()
```

### 2.6 seaborn 统计图

seaborn 基于 matplotlib 封装，一行代码出统计图，配色更美观。

```python
import seaborn as sns

# 设置主题
sns.set_theme(style="whitegrid")

# 箱线图：不同分类的价格分布（直观展示中位数与离群点）
plt.figure(figsize=(10, 6))
sns.boxplot(data=df, x="category", y="price")
plt.xticks(rotation=45)
plt.title("各分类价格分布箱线图")
plt.show()

# 直方图 + 核密度估计
sns.histplot(df["price"], kde=True)
plt.show()

# 热力图：各分类×评分 的数量矩阵
pivot_count = pd.crosstab(df["category"], df["rating"])
plt.figure(figsize=(8, 6))
sns.heatmap(pivot_count, annot=True, cmap="YlGnBu", fmt="d")
plt.show()
```

### 2.7 plotly 交互图

静态图片无法缩放/悬浮，plotly 生成 **HTML 交互图**，适合报告与分享。

```python
import plotly.express as px

# 交互式柱状图（悬停显示数值）
fig = px.bar(
    df.groupby("category")["price"].mean().reset_index(),
    x="category",
    y="price",
    title="各分类平均价格",
)
fig.write_html("category_price.html")   # 导出为独立 HTML
fig.show()

# 交互式折线图
fig2 = px.line(daily.reset_index(), x="created_at", y=0, title="每日订单趋势")
fig2.show()
```

**三个绘图库定位对比**

| 库 | 定位 | 交互性 | 学习成本 |
|:-----|:-----|:-------|:---------|
| matplotlib | 底层基础库，灵活可控 | 无 | 中 |
| seaborn | 统计图封装，美观省事 | 无 | 低 |
| plotly | 交互式图表，适合报告 | 强 | 低 |

## 五、实践项目

### 项目目标

结合前两个模块的爬虫数据，完成「采集 → 清洗 → 分析 → 可视化 → 报表」的全流程，输出一份多图表分析报告。

**步骤**：

1. 读取爬虫导出的 `books.csv`，用 pandas 概览数据结构
2. 清洗数据：处理缺失、去重、识别异常价格
3. 用 `groupby` / `pivot_table` 统计各分类图书数量、平均价格、评分分布
4. 用 matplotlib / seaborn 绘制柱状图、箱线图、热力图
5. 用 plotly 生成交互式图表，导出 HTML
6. 将结果写入多 Sheet 的 Excel 报表
