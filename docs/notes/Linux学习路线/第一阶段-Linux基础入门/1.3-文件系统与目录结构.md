# 文件系统与目录结构

## 一、FHS 标准目录结构

Linux 遵循 **FHS（Filesystem Hierarchy Standard，文件系统层次结构标准）**，所有目录从根 `/` 开始。

### 1.1 核心目录一览

```text
/
├── /bin        → 基本命令（已链接到 /usr/bin）
├── /boot       → 启动文件（内核、grub）
├── /dev        → 设备文件（硬盘、键盘、终端）
├── /etc        → 系统配置文件 ⭐ 最常用
├── /home       → 用户主目录 ⭐
│   └── /home/username/
├── /lib        → 共享库文件（已链接到 /usr/lib）
├── /media      → 自动挂载的可移动媒体
├── /mnt        → 手动临时挂载点
├── /opt        → 第三方独立软件
├── /proc       → 虚拟文件系统（进程/内核信息）
├── /root       → root 用户的主目录
├── /run        → 运行时临时文件（tmpfs，重启清空）
├── /sbin       → 系统管理命令（已链接到 /usr/sbin）
├── /srv        → 服务数据目录
├── /sys        → 内核与设备信息（虚拟）
├── /tmp        → 临时文件（重启可能清空）
├── /usr        → 用户软件与库 ⭐
│   ├── /usr/bin/      → 用户命令
│   ├── /usr/lib/      → 库文件
│   ├── /usr/local/    → 本地编译安装的软件
│   └── /usr/share/    → 共享数据（文档、图标）
└── /var        → 可变数据 ⭐
    ├── /var/log/      → 日志文件
    ├── /var/lib/      → 应用状态数据（数据库、包管理器）
    ├── /var/cache/    → 缓存
    └── /var/tmp/      → 持久化临时文件
```

### 1.2 重要目录详解

| 目录 | 用途 | 示例 |
|:-----|:-----|:-----|
| `/etc` | 所有系统级配置文件 | `/etc/ssh/sshd_config`、`/etc/nginx/nginx.conf` |
| `/home` | 普通用户的家目录 | `/home/alice/Documents` |
| `/var/log` | 系统和应用日志 | `/var/log/syslog`、`/var/log/nginx/access.log` |
| `/usr/local` | 手动编译安装的软件 | `/usr/local/bin/myapp` |
| `/tmp` | 所有用户可写的临时目录 | 建议用 `/var/tmp` 存重要临时文件 |
| `/opt` | 独立第三方软件包 | `/opt/google/chrome` |

> ⚠️ **注意事项**：
> - `/tmp` 目录在重启后可能被清空（取决于配置），不要存放重要文件。
> - 不要随意修改 `/etc` 下的配置文件，修改前务必备份。
> - `/proc` 和 `/sys` 是虚拟文件系统，不要直接编辑其中的文件。

## 二、文件类型

Linux 中一切皆文件。使用 `ls -l` 第一个字符查看文件类型：

| 字符 | 类型 | 说明 |
|:-----|:-----|:-----|
| `-` | 普通文件 | 文本、二进制、图片等 |
| `d` | 目录 | 文件夹 |
| `l` | 符号链接（软链接） | 类似 Windows 快捷方式 |
| `b` | 块设备文件 | 硬盘、U盘（/dev/sda） |
| `c` | 字符设备文件 | 键盘、鼠标（/dev/tty） |
| `p` | 管道文件 | 进程间通信 |
| `s` | 套接字文件 | 网络通信 |

```bash
$ ls -l /dev/sda
brw-rw---- 1 root disk 8, 0 Jun 22 10:00 /dev/sda
# b = 块设备

$ ls -l /etc/ssh/sshd_config
-rw-r--r-- 1 root root 2766 Jun 22 10:00 /etc/ssh/sshd_config
# - = 普通文件

$ ls -l /usr/bin/python3
lrwxrwxrwx 1 root root 10 Jun 22 10:00 /usr/bin/python3 -> python3.12
# l = 符号链接
```

## 三、inode 与链接

### 3.1 inode 概念

每个文件在磁盘上都有一个 **inode（索引节点）**，存储文件的元数据：

- 文件大小、所有者、权限
- 时间戳（创建/修改/访问时间）
- 数据块在磁盘上的位置
- **不包含**文件名（文件名存在目录项中）

```bash
# 查看文件的 inode 号
ls -i filename
stat filename
```

### 3.2 硬链接 vs 软链接

| 对比维度 | 硬链接 (Hard Link) | 软链接 (Symbolic Link) |
|:---------|:------------------|:----------------------|
| 本质 | 指向**同一个 inode** | 指向**文件路径**（独立 inode） |
| 跨文件系统 | ❌ 不可以 | ✅ 可以 |
| 链接目录 | ❌ 不允许 | ✅ 可以 |
| 删除源文件 | 链接仍可用 | 链接失效（断链） |
| 创建命令 | `ln source link` | `ln -s source link` |

```bash
# 硬链接：同一个 inode
$ echo "hello" > file1
$ ln file1 file2          # 创建硬链接
$ ls -li file1 file2
123456 -rw-r--r-- 2 user user 6 Jun 22 10:00 file1
123456 -rw-r--r-- 2 user user 6 Jun 22 10:00 file2
#      ↑ inode 相同                 ↑ 链接计数 = 2

# 软链接：不同 inode
$ ln -s file1 file3       # 创建软链接
$ ls -li file1 file3
123456 -rw-r--r-- 1 user user 6 Jun 22 10:00 file1
123457 lrwxrwxrwx 1 user user 5 Jun 22 10:00 file3 -> file1
#      ↑ inode 不同
```

```text
硬链接原理：                      软链接原理：
┌──────────┐                    ┌──────────┐
│ 目录项A  │──→ inode #100      │ 目录项A  │──→ inode #100 (数据="hello")
│ 目录项B  │──→ inode #100      │ 目录项B  │──→ inode #101 (数据="目录项A路径")
└──────────┘                    └──────────┘
 两个名字同一个文件                 B 指向 A 的路径
```

## 四、挂载（Mount）

Linux 将**所有存储设备**（硬盘、U盘、光盘）挂载到统一目录树中，不像 Windows 用盘符（C:、D:）区分。

```bash
# 查看当前挂载情况
df -h                   # 人类可读格式
mount | column -t       # 详细挂载信息
lsblk                   # 列出块设备树

# 临时挂载 U 盘
sudo mount /dev/sdb1 /mnt/usb

# 卸载
sudo umount /mnt/usb

# 永久挂载（编辑 /etc/fstab）
sudo vim /etc/fstab
# UUID=xxx-xxx  /data  ext4  defaults  0  2
```

**/etc/fstab 字段说明**：

```text
# <设备>           <挂载点>  <文件系统>  <选项>     <dump>  <fsck>
UUID=abc-123-def  /data     ext4        defaults   0       2
```

## 五、常用文件系统类型

| 文件系统 | 特点 | 适用场景 |
|:---------|:-----|:---------|
| **ext4** | Linux 默认、稳定可靠、最大 1EB | 通用（Ubuntu 默认） |
| **XFS** | 高性能、适合大文件、RHEL 默认 | 数据库、大文件存储 |
| **Btrfs** | 快照、压缩、写时复制（COW） | 高级存储管理 |
| **ZFS** | 数据完整性校验、快照、压缩 | NAS、数据安全场景 |
| **NTFS** | Windows 默认文件系统 | 双系统数据共享 |
| **tmpfs** | 内存文件系统、重启丢失 | /tmp、/run |

## 📝 实践项目

### 目标

熟悉 Linux 目录结构和文件类型。

### 步骤

1. **浏览目录树**
   ```bash
   # 用 tree 命令查看结构（需安装 tree）
   sudo apt install tree -y
   tree -L 2 /          # 显示两层目录结构
   tree -d -L 2 /       # 只显示目录
   ```

2. **创建链接实验**
   ```bash
   mkdir ~/link-test && cd ~/link-test
   echo "original content" > original.txt

   # 创建硬链接
   ln original.txt hard.txt

   # 创建软链接
   ln -s original.txt soft.txt

   # 查看 inode 差异
   ls -li

   # 删除源文件，观察链接变化
   rm original.txt
   cat hard.txt      # ✅ 正常读取
   cat soft.txt      # ❌ 报错：No such file or directory
   ```

3. **查看磁盘挂载信息**
   ```bash
   df -h
   lsblk -f          # 显示文件系统类型和 UUID
   cat /etc/fstab    # 查看永久挂载配置
   ```

4. **查看文件 inode 信息**
   ```bash
   stat /etc/passwd
   stat /etc/hostname
   ```
